# Reactive Programming

Reactive Programming is a paradigm centered around **data streams and the propagation of change**. Instead of asking for a value when you need it (pull), you declare how values should flow and react to changes as they happen (push).

It is particularly useful for handling asynchronous events like user interactions, WebSocket messages, HTTP responses, and real-time data.

<a href="https://rxjs.dev/guide/overview" target="_blank">RxJS Documentation</a>

## Core Concepts

### Observable

An Observable is a data source that emits values over time. It can emit zero or more values and then complete or error.

```typescript
import { Observable } from "rxjs";

const numbers$ = new Observable<number>(subscriber => {
  subscriber.next(1);
  subscriber.next(2);
  subscriber.next(3);
  subscriber.complete();
});
```

OBS: The `$` suffix is a convention to indicate a variable holds an Observable.

### Observer

An Observer subscribes to an Observable and reacts to what it emits.

```typescript
numbers$.subscribe({
  next: value => console.log(value),  // called for each emitted value
  error: err => console.error(err),   // called on error
  complete: () => console.log("done") // called when stream ends
});
// 1
// 2
// 3
// done
```

### Subscription

The object returned by `.subscribe()`. Call `.unsubscribe()` to stop listening and prevent memory leaks.

```typescript
const subscription = numbers$.subscribe(value => console.log(value));
subscription.unsubscribe();
```

## Creation Functions

Common ways to create Observables from existing data:

```typescript
import { of, from, fromEvent, interval } from "rxjs";

of(1, 2, 3);                          // emits 1, 2, 3 then completes
from([10, 20, 30]);                   // emits each array item
from(fetch("/api/users"));            // wraps a Promise
fromEvent(button, "click");           // emits on every button click
interval(1000);                       // emits 0, 1, 2... every second
```

## Operators (Pipeable)

Operators transform, filter, and combine streams. They are applied using `.pipe()`.

### map

Transforms each emitted value.

```typescript
import { map } from "rxjs/operators";

of(1, 2, 3).pipe(
  map(n => n * 2)
).subscribe(console.log); // 2, 4, 6
```

### filter

Passes only values that meet a condition.

```typescript
import { filter } from "rxjs/operators";

of(1, 2, 3, 4, 5).pipe(
  filter(n => n % 2 === 0)
).subscribe(console.log); // 2, 4
```

### debounceTime

Waits for a pause in emissions before passing the value. Useful for search inputs.

```typescript
import { debounceTime } from "rxjs/operators";

fromEvent(searchInput, "input").pipe(
  debounceTime(300),
  map((event: Event) => (event.target as HTMLInputElement).value)
).subscribe(value => search(value));
```

### switchMap

Maps each value to a new Observable and cancels the previous one. Essential for HTTP requests triggered by user input.

```typescript
import { switchMap } from "rxjs/operators";

searchTerm$.pipe(
  debounceTime(300),
  switchMap(term => from(fetch(`/api/search?q=${term}`)))
).subscribe(results => renderResults(results));
```

## Reactive in the Browser (without RxJS)

JavaScript has native reactive primitives:

**EventEmitter / addEventListener:**

```typescript
button.addEventListener("click", () => console.log("clicked"));
```

**Promises** — reactive for a single async value:

```typescript
fetch("/api/user")
  .then(res => res.json())
  .then(user => console.log(user));
```

**Async/Await** — syntactic sugar over Promises:

```typescript
async function loadUser(id: number) {
  const res = await fetch(`/api/user/${id}`);
  const user = await res.json();
  return user;
}
```

## Reactive vs Imperative — Same Problem

```typescript
// imperative — you ask for the value
const total = cart.items.reduce((sum, item) => sum + item.price, 0);

// reactive — you declare how total should react to changes in the cart
const total$ = cartItems$.pipe(
  map(items => items.reduce((sum, item) => sum + item.price, 0))
);

total$.subscribe(total => renderTotal(total));
```
