# Functional Programming

Functional Programming is a paradigm that treats computation as the evaluation of **pure functions**, avoids shared mutable state, and favors data transformation over step-by-step instructions.

JavaScript and TypeScript support functional programming natively alongside OOP.


## Core Concepts

### Pure Functions

A function is pure if:
1. Given the same inputs, it always returns the same output.
2. It produces no side effects (no mutations, no I/O, no global state changes).

*Example:*

```typescript
// impure — depends on external state
let taxRate = 0.1;
function calculateTax(price: number): number {
  return price * taxRate; // result changes if taxRate changes
}

// pure — self-contained
function calculateTax(price: number, taxRate: number): number {
  return price * taxRate;
}
```

### Immutability

Never modify existing data — create new data structures with the changes applied.

*Example:*

```typescript
// bad — mutates original array
function addItem(cart: string[], item: string): string[] {
  cart.push(item); // modifies the original
  return cart;
}

// good — returns a new array
function addItem(cart: string[], item: string): string[] {
  return [...cart, item];
}
```

### First-Class and Higher-Order Functions

In JavaScript, functions are first-class citizens — they can be assigned to variables, passed as arguments, and returned from other functions.

A **higher-order function** takes a function as an argument or returns one.

*Example:*

```typescript
// passing a function as an argument
function applyDiscount(price: number, discount: (p: number) => number): number {
  return discount(price);
}

const tenPercent = (price: number) => price * 0.9;
applyDiscount(100, tenPercent); // 90

// returning a function (closure)
function multiplier(factor: number) {
  return (value: number) => value * factor;
}

const double = multiplier(2);
const triple = multiplier(3);
double(5); // 10
triple(5); // 15
```

## Array Methods (Functional Style)

These built-in methods follow functional principles — they do not mutate the original array.

### .map()

Transforms each element and returns a new array.

```typescript
const prices = [10, 20, 30];
const discounted = prices.map(price => price * 0.9);
// [9, 18, 27]
```

### .filter()

Returns a new array with only the elements that pass a condition.

```typescript
const users = [{ name: "Ana", age: 17 }, { name: "Bob", age: 25 }];
const adults = users.filter(user => user.age >= 18);
// [{ name: "Bob", age: 25 }]
```

### .reduce()

Accumulates all elements into a single value.

```typescript
const items = [{ price: 10, qty: 2 }, { price: 5, qty: 3 }];
const total = items.reduce((sum, item) => sum + item.price * item.qty, 0);
// 35
```

### .find() / .findIndex()

Returns the first element (or its index) that matches a condition.

```typescript
const users = [{ id: 1, name: "Ana" }, { id: 2, name: "Bob" }];
const user = users.find(u => u.id === 2); // { id: 2, name: "Bob" }
```

### Chaining

Methods can be chained to build readable data pipelines.

```typescript
const result = orders
  .filter(order => order.isPaid)
  .map(order => order.total)
  .reduce((sum, total) => sum + total, 0);
```

## Function Composition

Combining small functions to build more complex ones.

*Example:*

```typescript
const trim = (str: string) => str.trim();
const toLowerCase = (str: string) => str.toLowerCase();
const removeSpaces = (str: string) => str.replace(/\s+/g, "-");

const slugify = (str: string) => removeSpaces(toLowerCase(trim(str)));

slugify("  Hello World  "); // "hello-world"
```

## Closures

A function that remembers variables from its outer scope even after the outer function has returned.

*Example:*

```typescript
function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    decrement: () => --count,
    value: () => count,
  };
}

const counter = createCounter();
counter.increment(); // 1
counter.increment(); // 2
counter.value();     // 2
```
