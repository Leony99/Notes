# Procedural Programming

Procedural Programming is a paradigm where code is organized as a sequence of instructions executed step by step. State is stored in variables, and behavior is expressed in procedures (functions) that read and modify that state.

It is the most intuitive paradigm and the foundation of most programming languages. JavaScript, Java, and TypeScript all support procedural code alongside OOP and functional styles.

## Characteristics

- Code runs top to bottom, line by line.
- State lives in variables (local or global).
- Functions group related instructions and can be called repeatedly.
- No encapsulation — any function can access and modify any variable in scope.

*Example:*

```typescript
let balance = 1000;

function deposit(amount: number): void {
  balance += amount;
}

function withdraw(amount: number): void {
  if (amount > balance) {
    console.log("Insufficient funds");
    return;
  }
  balance -= amount;
}

function printBalance(): void {
  console.log(`Balance: $${balance}`);
}

deposit(500);
withdraw(200);
printBalance(); // Balance: $1300
```

## When It Makes Sense

Procedural code is appropriate for:

- **Scripts** — one-off tasks like data migration, file processing, CLI tools.
- **Glue code** — orchestrating calls between systems in a simple linear flow.
- **Simple utilities** — small helper functions with no shared state.

For larger applications, the lack of encapsulation becomes a problem: any part of the code can modify shared state, making bugs hard to trace and test.

## Procedural vs OOP — Same Problem

```typescript
// Procedural
let stock = 100;

function reserveStock(quantity: number): boolean {
  if (quantity > stock) return false;
  stock -= quantity;
  return true;
}

// OOP — state is owned and protected by the object
class Inventory {
  #stock: number;

  constructor(initialStock: number) {
    this.#stock = initialStock;
  }

  reserve(quantity: number): boolean {
    if (quantity > this.#stock) return false;
    this.#stock -= quantity;
    return true;
  }
}
```

In the procedural version, `stock` is accessible and modifiable from anywhere. In the OOP version, only `Inventory` can change it.

## Control Flow

Procedural code makes heavy use of control structures to direct execution:

```typescript
// conditionals
if (user.isAdmin) {
  grantAccess();
} else {
  denyAccess();
}

// loops
for (const item of cart.items) {
  processItem(item);
}

// early return
function findUser(id: number): User | null {
  if (!id) return null;
  return db.find(id);
}
```
