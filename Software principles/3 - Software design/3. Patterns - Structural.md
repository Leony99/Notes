# Design Patterns – Structural

Structural patterns deal with how classes and objects are composed to form larger structures. They help ensure that when parts of a system change, the entire structure does not need to be rebuilt.

<a href="https://refactoring.guru/design-patterns/structural-patterns" target="_blank">Structural Patterns – Refactoring Guru</a>

## Adapter

Converts the interface of a class into another interface that clients expect. Allows incompatible interfaces to work together.

*Example:*

```typescript
// third-party payment library with a different interface
class StripeSDK {
  makePayment(amountInCents: number, currency: string): void {
    console.log(`Stripe: charging ${amountInCents} ${currency}`);
  }
}

// your application expects this interface
interface PaymentProcessor {
  pay(amount: number): void;
}

// adapter bridges the two
class StripeAdapter implements PaymentProcessor {
  private stripe = new StripeSDK();

  pay(amount: number): void {
    this.stripe.makePayment(amount * 100, "USD"); // converts dollars to cents
  }
}

// usage — your code only knows about PaymentProcessor
const processor: PaymentProcessor = new StripeAdapter();
processor.pay(49.99);
```

## Decorator

Attaches additional behavior to an object dynamically, without modifying its class or subclassing it. Decorators wrap the original object.

*Example:*

```typescript
interface Logger {
  log(message: string): void;
}

class ConsoleLogger implements Logger {
  log(message: string): void {
    console.log(message);
  }
}

// decorator — adds timestamps without changing ConsoleLogger
class TimestampLogger implements Logger {
  constructor(private logger: Logger) {}

  log(message: string): void {
    this.logger.log(`[${new Date().toISOString()}] ${message}`);
  }
}

// decorator — adds log level prefix
class PrefixLogger implements Logger {
  constructor(private logger: Logger, private prefix: string) {}

  log(message: string): void {
    this.logger.log(`[${this.prefix}] ${message}`);
  }
}

// stack decorators
const logger = new PrefixLogger(new TimestampLogger(new ConsoleLogger()), "INFO");
logger.log("Server started");
// [INFO] [2024-01-15T10:30:00.000Z] Server started
```

OBS: TypeScript has a native `@Decorator` syntax (used heavily in NestJS and Angular) that implements this same pattern.

## Facade

Provides a simplified interface to a complex subsystem. Hides the complexity behind a single, easy-to-use class.

*Example:*

```typescript
// complex subsystems
class VideoEncoder { encode(file: string) { console.log(`Encoding ${file}`); } }
class ThumbnailGenerator { generate(file: string) { console.log(`Generating thumbnail for ${file}`); } }
class CDNUploader { upload(file: string) { console.log(`Uploading ${file} to CDN`); } }
class Database { saveMetadata(file: string) { console.log(`Saving metadata for ${file}`); } }

// facade — one simple method orchestrates everything
class VideoUploadFacade {
  private encoder = new VideoEncoder();
  private thumbnailer = new ThumbnailGenerator();
  private cdn = new CDNUploader();
  private db = new Database();

  upload(file: string): void {
    this.encoder.encode(file);
    this.thumbnailer.generate(file);
    this.cdn.upload(file);
    this.db.saveMetadata(file);
  }
}

// usage — client doesn't need to know about the subsystems
const uploader = new VideoUploadFacade();
uploader.upload("lecture.mp4");
```

## Proxy

Provides a substitute or placeholder for another object to control access to it. Common uses: lazy initialization, access control, caching, logging.

*Example:*

```typescript
interface UserService {
  getUser(id: number): { id: number; name: string };
}

class RealUserService implements UserService {
  getUser(id: number) {
    console.log(`Fetching user ${id} from database`);
    return { id, name: "Ana" }; // simulates DB call
  }
}

// caching proxy
class CachedUserService implements UserService {
  private cache = new Map<number, { id: number; name: string }>();
  private service = new RealUserService();

  getUser(id: number) {
    if (this.cache.has(id)) {
      console.log(`Returning cached user ${id}`);
      return this.cache.get(id)!;
    }
    const user = this.service.getUser(id);
    this.cache.set(id, user);
    return user;
  }
}

const service: UserService = new CachedUserService();
service.getUser(1); // Fetching user 1 from database
service.getUser(1); // Returning cached user 1
```

## Composite

Composes objects into tree structures to represent part-whole hierarchies. Lets clients treat individual objects and compositions uniformly.

*Example:*

```typescript
interface FileSystemItem {
  getName(): string;
  getSize(): number;
}

class File implements FileSystemItem {
  constructor(private name: string, private size: number) {}
  getName() { return this.name; }
  getSize() { return this.size; }
}

class Folder implements FileSystemItem {
  private children: FileSystemItem[] = [];

  constructor(private name: string) {}

  add(item: FileSystemItem) { this.children.push(item); }
  getName() { return this.name; }
  getSize() { return this.children.reduce((total, item) => total + item.getSize(), 0); }
}

const root = new Folder("root");
const src = new Folder("src");
src.add(new File("index.ts", 120));
src.add(new File("app.ts", 340));
root.add(src);
root.add(new File("package.json", 80));

console.log(root.getSize()); // 540
```
