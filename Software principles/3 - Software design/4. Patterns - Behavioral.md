# Design Patterns – Behavioral

Behavioral patterns define how objects communicate and distribute responsibility. They focus on the interaction and algorithms between objects.

<a href="https://refactoring.guru/design-patterns/behavioral-patterns" target="_blank">Behavioral Patterns – Refactoring Guru</a>

## Observer

Defines a one-to-many relationship: when one object (subject) changes state, all its dependents (observers) are notified automatically. The foundation of event systems and reactive programming.

*Example:*

```typescript
interface Observer {
  update(event: string, data: unknown): void;
}

class EventEmitter {
  private listeners = new Map<string, Observer[]>();

  subscribe(event: string, observer: Observer): void {
    const existing = this.listeners.get(event) ?? [];
    this.listeners.set(event, [...existing, observer]);
  }

  notify(event: string, data: unknown): void {
    this.listeners.get(event)?.forEach(obs => obs.update(event, data));
  }
}

class Order extends EventEmitter {
  private status = "pending";

  updateStatus(newStatus: string): void {
    this.status = newStatus;
    this.notify("statusChanged", { status: newStatus });
  }
}

class EmailNotifier implements Observer {
  update(event: string, data: unknown) {
    console.log(`Email sent for event: ${event}`, data);
  }
}

class InventoryUpdater implements Observer {
  update(event: string, data: unknown) {
    console.log(`Inventory updated for event: ${event}`, data);
  }
}

const order = new Order();
order.subscribe("statusChanged", new EmailNotifier());
order.subscribe("statusChanged", new InventoryUpdater());
order.updateStatus("shipped"); // both observers are notified
```

OBS: Node.js's built-in `EventEmitter` and browser's `addEventListener` are implementations of this pattern.

## Strategy

Defines a family of algorithms, encapsulates each one, and makes them interchangeable. Allows the algorithm to vary independently from the clients that use it.

*Example:*

```typescript
interface SortStrategy {
  sort(data: number[]): number[];
}

class BubbleSort implements SortStrategy {
  sort(data: number[]): number[] {
    const arr = [...data];
    // bubble sort implementation
    return arr.sort((a, b) => a - b); // simplified
  }
}

class QuickSort implements SortStrategy {
  sort(data: number[]): number[] {
    const arr = [...data];
    return arr.sort((a, b) => a - b); // simplified
  }
}

class DataProcessor {
  constructor(private strategy: SortStrategy) {}

  setStrategy(strategy: SortStrategy): void {
    this.strategy = strategy;
  }

  process(data: number[]): number[] {
    return this.strategy.sort(data);
  }
}

const processor = new DataProcessor(new BubbleSort());
processor.process([3, 1, 4, 1, 5]);

processor.setStrategy(new QuickSort()); // swap strategy at runtime
processor.process([9, 2, 7, 3]);
```

## Command

Encapsulates a request as an object, allowing you to parameterize clients with different requests, queue or log requests, and support undo operations.

*Example:*

```typescript
interface Command {
  execute(): void;
  undo(): void;
}

class TextEditor {
  private content = "";

  write(text: string) { this.content += text; }
  delete(length: number) { this.content = this.content.slice(0, -length); }
  getContent() { return this.content; }
}

class WriteCommand implements Command {
  constructor(private editor: TextEditor, private text: string) {}

  execute() { this.editor.write(this.text); }
  undo() { this.editor.delete(this.text.length); }
}

class CommandHistory {
  private history: Command[] = [];

  execute(command: Command): void {
    command.execute();
    this.history.push(command);
  }

  undo(): void {
    const command = this.history.pop();
    command?.undo();
  }
}

const editor = new TextEditor();
const history = new CommandHistory();

history.execute(new WriteCommand(editor, "Hello"));
history.execute(new WriteCommand(editor, " World"));
console.log(editor.getContent()); // Hello World

history.undo();
console.log(editor.getContent()); // Hello
```

## Iterator

Provides a way to sequentially access elements of a collection without exposing its underlying structure.

*Example:*

```typescript
// JavaScript has native iterator support via Symbol.iterator
class NumberRange {
  constructor(private start: number, private end: number) {}

  [Symbol.iterator]() {
    let current = this.start;
    const end = this.end;
    return {
      next(): IteratorResult<number> {
        if (current <= end) {
          return { value: current++, done: false };
        }
        return { value: 0, done: true };
      }
    };
  }
}

const range = new NumberRange(1, 5);
for (const num of range) {
  console.log(num); // 1, 2, 3, 4, 5
}
```

## Template Method

Defines the skeleton of an algorithm in a base class, deferring some steps to subclasses. Subclasses can override specific steps without changing the overall structure.

*Example:*

```typescript
abstract class ReportGenerator {
  // template method — defines the steps
  generate(): void {
    this.fetchData();
    this.processData();
    this.renderReport();
  }

  abstract fetchData(): void;
  abstract processData(): void;

  renderReport(): void {
    console.log("Rendering report...");
  }
}

class SalesReport extends ReportGenerator {
  fetchData() { console.log("Fetching sales data from DB"); }
  processData() { console.log("Calculating totals and margins"); }
}

class InventoryReport extends ReportGenerator {
  fetchData() { console.log("Fetching inventory data from warehouse API"); }
  processData() { console.log("Grouping items by category"); }
}

new SalesReport().generate();
```
