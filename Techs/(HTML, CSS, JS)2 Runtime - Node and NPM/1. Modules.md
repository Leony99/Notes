# Modules

Node has two module systems: CommonJS (`require`), the original one, and ES Modules (`import`), the JavaScript standard.

- `.cjs` = always CommonJS
- `.mjs` = always ES Modules
- `.js` = depends on the `"type"` field in `package.json` (`"commonjs"` is the default, `"module"` for ES Modules)

## CommonJS

**module** is an object that represents the current module.

**module.exports** is the key that holds an object with the exported values from that module.

**exports** and **this** are references to **module.exports**. (Do not change the reference).

### Require module

```javascript
const myModule = require('./my-module');
```

### Specifies the value that the module will export

```javascript
module.exports = 'value';
```

```javascript
module.exports = {
  a: 'valueA',
  b: 'valueB',
};
```

```javascript
module.exports.a = 'valueA';
module.exports.b = 'valueB';
```

```javascript
exports.a = 'valueA';
exports.b = 'valueB';
this.a = 'valueA';
this.b = 'valueB';
```

OBS: `exports = 'value'` does not work, because it only changes the local reference and not `module.exports`.

## ES Modules

*Example:*

```json
{
  "type": "module"
}
```

```javascript
// math.js
export const PI = 3.14;
export default function sum(a, b) {
  return a + b;
}
```

```javascript
// index.js
import sum, { PI } from './math.js';
```

OBS: In ES Modules the file extension in the import is mandatory, and `require`, `module` and `__dirname` do not exist.

## Built-in modules

Modules that come with Node, no installation needed.

- `fs`, `fs/promises`: Files.
- `path`: File paths.
- `http`: HTTP server and client.
- `os`: System information.
- `crypto`: Cryptography.
- `events`: EventEmitter.

*Example:*

```javascript
const http = require('http');

const server = http.createServer((req, res) => {
  res.end('Hello World!');
});

server.listen(3000);
```
