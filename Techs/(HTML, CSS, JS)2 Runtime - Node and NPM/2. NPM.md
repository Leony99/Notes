# NPM

**Node Package Manager (npm)** is a package manager for Node.js third party modules.

## Installing packages

- **dependencies**: Needed to run the application.
- **devDependencies**: Needed only during development (`--save-dev` or `-D`).
- **Global**: Installed on the machine, usually CLI tools (`-g`).

*Example:*

```console
npm install express
npm install jest --save-dev
npm install -g typescript
```

OBS: `npm install` without a name installs everything listed in `package.json`. In CI and Docker, prefer `npm ci`, which installs exactly what is in `package-lock.json`.

## Versions

**MAJOR.MINOR.PATCH**

- `1.2.3` = exactly this version
- `^1.2.3` = compatible updates (`1.x.x`), the default
- `~1.2.3` = only patches (`1.2.x`)

## Scripts

The `scripts` of `package.json` are shortcuts for commands. They can use the binaries from `node_modules/.bin` directly.

*Example:*

```json
{
  "scripts": {
    "dev": "node --watch index.js",
    "build": "tsc",
    "test": "jest"
  }
}
```

```console
npm run dev
npm test
```

OBS: `start` and `test` do not need `run`.

## npx

Runs a package binary without installing it globally.

*Example:*

```console
npx create-next-app@latest
```
