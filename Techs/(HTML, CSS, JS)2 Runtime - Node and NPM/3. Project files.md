# Project files

**package.json** stores critical metadata about a project, defining the rules required to run your application and the dependencies of the project.

**package-lock.json** is a lockfile that holds detailed information about the dependencies of the project, with the exact installed versions.

**node_modules** is the folder that contains all the downloaded dependencies.

*Example:*

```json
{
  "name": "my-app",
  "version": "1.0.0",
  "type": "module",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "dependencies": {
    "express": "^5.0.0"
  },
  "devDependencies": {
    "jest": "^29.0.0"
  }
}
```

OBS: Commit `package.json` and `package-lock.json`. Add `node_modules` to `.gitignore`, as it can be recreated with `npm install`.
