# Node.js

Node.js is a runtime that executes JavaScript outside the browser. It is built on the V8 engine, the same one used by Chrome, and is used to create servers, CLIs and tools.

<a href="https://nodejs.org/docs/latest/api/" target="_blank">Node.js Documentation</a>

<a href="https://docs.npmjs.com/" target="_blank">NPM Documentation</a>

## Installation

**Windows/Mac/Linux:** Install the LTS version from <a href="https://nodejs.org/" target="_blank">nodejs.org</a>. NPM comes with it.

Verify the installation:

```console
node --version
npm --version
```

## Core concepts

- **Runtime**: The environment that runs JavaScript (V8 plus system APIs like files and network).
- **Event loop**: Runs asynchronous tasks in a single thread, without blocking the program.
- **Module**: A file with its own scope that exports values to other files.
- **Package**: A folder with a `package.json`, usually downloaded with NPM.
- **NPM**: The package manager for Node.js third party modules.

OBS: In Node there is no `document` or `window`. They belong to the browser, while Node adds `process`, `fs`, `path` and `http`.

## Run a file

```console
node index.js
```

*Example:*

```javascript
// index.js
const { readFile } = require('fs/promises');

async function main() {
  const content = await readFile('notes.txt', 'utf-8');
  console.log(content);
}

main();
```

## Environment variables

Read them with `process.env`.

*Example:*

```javascript
const port = process.env.PORT || 3000;
```

```console
node --env-file=.env index.js
```
