# Commands

Quick reference of the most used Node and NPM commands.

## Node

| Command | What it does |
|---|---|
| `node 'filetorun'` | Node run file |
| `node --watch 'filetorun'` | Run file and restart it on changes |
| `node --env-file=.env 'filetorun'` | Run file loading a `.env` |

## NPM

| Command | What it does |
|---|---|
| `npm init` | Start npm (create package.json) |
| `npm init -y` | Start npm with the default answers |
| `npm run 'script'` | Run script |
| `npm install` | Install modules packages listed in package.json |
| `npm ci` | Clean install from package-lock.json |
| `npm install 'module'` | Install module package locally |
| `npm install 'module' --save-dev` | Install module package locally as a dev dependency |
| `npm -g install 'module'` | Install module package globally |
| `npm -g install 'module' --save-dev` | Install module package globally as a dev dependency |
| `npm uninstall 'module'` | Remove a module package |
| `npm update` | Update packages within the allowed versions |
| `npm outdated` | Check outdated packages |
| `npm audit` | Check known vulnerabilities |
| `npm list` | Check installed dependencies |
| `npm list -g` | Check installed dependencies (globally) |
| `npx 'package'` | Run a package without installing it globally |
