# Java

Java is a compiled, statically typed and object-oriented language. The code is compiled to bytecode, which runs on any machine with a JVM.

<a href="https://dev.java/learn/" target="_blank">Java Documentation</a>

<a href="https://docs.oracle.com/en/java/javase/21/docs/api/" target="_blank">Java API Reference</a>

## Installation

Install a JDK, like <a href="https://adoptium.net/" target="_blank">Eclipse Temurin</a>.

Verify the installation:

```console
java --version
javac --version
```

## Core concepts

- **JDK**: Java Development Kit. The tools to develop (compiler, JRE).
- **JRE**: Java Runtime Environment. What is needed to run.
- **JVM**: Java Virtual Machine. Runs the bytecode.
- **Bytecode**: The `.class` files generated by the compiler.
- **Package**: A folder that organizes classes.
- **Class**: The blueprint of objects. All Java code is inside a class.

## Basic flow

```
Main.java  ──javac──▶  Main.class  ──java──▶  JVM runs the program
```

## Commands

| Command | What it does |
|---|---|
| `javac Main.java` | Compiles a file |
| `java Main` | Runs a compiled class |
| `java Main.java` | Compiles and runs a single file |
| `java -jar app.jar` | Runs a `.jar` |
| `jar cfe app.jar Main *.class` | Packages the classes in a `.jar` |

OBS: In real projects, use Maven or Gradle to compile. See Techs → (Java)3 Tools - Maven.
