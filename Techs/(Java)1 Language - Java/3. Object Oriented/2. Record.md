# Record

Record `is a concise way to declare immutable classes` that mainly serve to carry data (Data Carrier Classes), eliminating a lot of boilerplate (getters, equals, hashCode, toString etc).

* Defines immutable fields (they are final and cannot be changed).

* The compiler automatically generates:
    * Constructor with all fields
    * Getters (without the get prefix)
    * equals() and hashCode()
    * toString()

* It may have additional methods, but cannot inherit from another class (only implement interfaces).

```java
//Class declaration
public record Person(String name, int age) {}
```

```java
///Object instantiation
public class Main {
    public static void main(String[] args) {
        Person p = new Person("John", 25);
        System.out.println(p.name());
        System.out.println(p.age()); 
        System.out.println(p);
    }
}
```
