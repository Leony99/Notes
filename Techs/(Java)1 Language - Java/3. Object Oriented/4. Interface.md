# Interface

Interface in Java `is a type of "contract" that defines a set of methods that a class should implement`. It is totally abstract by nature. (From Java 8, can also define constants, default and static methods).

Unlike a class, an interface cannot be instantiated directly and is used to specify what a class should do, but not how it should do.

* It has no attributes of instance (only constant - public static final).

* Methods without a body are abstract by default.

* A class can implement multiple interfaces (this is the way to have “multiple inheritance” in Java).

```java
//Interface declaration
public interface Bottle {
    void openBottle();
    void closeBottle();
}
```

### OBS - Functional Interface

A functional interface `is an interface with exactly one abstract method (single abstract method)`, also known as a SAM (Single Abstract Method). It is the basis for lambda expressions and method references, as the single abstract method defines the contract that the lambda or reference must implement.

```java
@FunctionalInterface
public interface Runnable {
    public abstract void run();
}
```
