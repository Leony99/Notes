# Abstract class

An abstract Java class `is a class that cannot be instantiated directly, you cannot create objects from it` using the `new` operator. `It serves as a "base" or "mold" to other classes`, defining a common behavior that their subclasses should follow or implement.

* May contain:
    * Abstract methods → declared but without body (subclasses is obliged to implement).
    * Concrete Methods → with normal implementation, which can be inherited directly.
    * Attributes → Variables that subclasses can also use/inherit.

```java
//Class declaration
public abstract class Person {
    public void speak(){
        System.out.print("Hello World!");
    }

    public abstract void eat();
}
```
