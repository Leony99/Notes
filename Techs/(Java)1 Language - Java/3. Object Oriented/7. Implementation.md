# Implementation(fulfills-a)

`Create a relation between a class and an interface/interfaces`. When a class implements an interface, we say it implements it. The class undertakes to provide the code (concrete implementation) of the methods defined in the interface.

```java
//Interface declaration
public interface Phone {
    String processor();
    int spaceInGB();
}
```

```java
//Interface implementation
public class SamsungPhone implements Phone {
    @Override
    public String processor() {
        return "Snapdragon 8000";
    }

    @Override
    public int spaceInGB() {
        return 256;
    }
}
```

## Multiple Inheritance

```java
//Interface implementation
public class SamsungPhone implements Phone, Android {
    @Override
    public String processor() {
        return "Snapdragon 8000";
    }

    @Override
    public int spaceInGB() {
        return 256;
    }

    @Override
    public String androidVersion() {
        return "Android 12";
    }
}
```
