# Inner class

## Inner Class (non-static)

An ordinary inner class `can only be instantiated if it is within an external class object`.

```java
class External {
    private int x = 10;

    class Inner {
        void show() {
            System.out.println("Value of x: " + x);
        }
    }
}

public class Main {
    public static void main(String[] args) {
        External external = new External();
        External.Inner inner = external.new Inner();
        inner.show();
    }
}
```

## Inner Class (static)

A static class `does not have access to members of the external class instance, only to static members`, that is, they have the same visibility as an external class.

```java
public class External {
   static int CountStatic = 0;
   int CountNonStatic = 0;

   public static class Inner {
        public void doInner() {
            System.out.println( CountStatic );
        }
   }
}
```

## Method Inner Class

`An inner class to a method`, can only be instantiated within this very method

```java
public class Main {
   public static void main(String[] args) {
      Outer o = new Outer();
      o.see();
   }
}

class Outer {
    private int x = 10;

    public void see() {
        System.out.println("before " + x);

        class Inner {
            public Inner() {
                x = 0;
            }
        }
        Inner i = new Inner();

        System.out.println("after " + x);
    }
}
```

## Anonymous Inner Class

It `is the inheritance of a certain class in an exclusive place`, that is, only in that particular point I need to redefine my super class.

```java
class Employee {
    public void work() {
        System.out.println("work");
    }
}

class EmployeeChart {
   Employee admin  = new Employee() {
        public void work() {
            System.out.println("order");
        }
   };

   Employee peao = new Employee() {
        public void work() {
            System.out.println("execute");
        }
   };
}
```

## Anonymous Inner Class(Interface)

Using the Event interface as an anonymous class, `a class that implements the Event interface is created, the interface is not instantiated directly`, so you are required to implement all of its methods.

```java
public class Example {
   public static void main(String[] args) {
        action( new Event() {
            public void click() {
                System.out.println("click");
            }
            public void drag() {
                System.out.println("drag");
            }
        });
   }

   public static void action(Event e) {
        e.click();
        e.drag();
   }
}

interface Event {
    public abstract void click();
    public abstract void drag();
}
```
