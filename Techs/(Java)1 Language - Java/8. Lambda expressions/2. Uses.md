# Uses

## Functional interfaces

Lambdas replace the anonymous classes used to implement interfaces like Runnable or Comparator.

```java
Runnable task = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
};

Runnable task2 = () -> System.out.println("Hello World!");
```

```java
Predicate<Integer> isEven = n -> n % 2 == 0;
System.out.println(isEven.test(4)); // Output: true
```

## Working with the Stream API

The Stream API (Java 8) uses lambdas to process collections in a functional way (filter, map, sort, etc.).

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

numbers.stream()
       .filter(n -> n % 2 == 0) // Lambda for Predicate<Integer>
       .forEach(n -> System.out.println(n)); // Lambda for Consumer<Integer>
```

## Defining inline behaviors

Lambdas allow you to pass behaviors as arguments to methods.

```java
IntBinaryOperator safeDivide = (a, b) -> { if(b == 0) return 0; return a/b; };
System.out.println(safeDivide.applyAsInt(10, 2));
System.out.println(safeDivide.applyAsInt(10, 0));
```

## Sorting collections

Lambdas simplify the implementation of Comparator to sort lists.

```java
List<String> words = Arrays.asList("banana", "apple", "fig");
words.sort((s1, s2) -> s1.length() - s2.length());
System.out.println(words); // Output: [fig, apple, banana]
```

## Asynchronous and parallel programming

Lambdas are used in APIs like CompletableFuture to handle asynchronous tasks.

```java
CompletableFuture.supplyAsync(() -> "Hello World!")
                 .thenAccept(s -> System.out.println(s));
```
