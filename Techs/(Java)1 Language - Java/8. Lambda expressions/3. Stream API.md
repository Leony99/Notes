# Stream API

A Stream `is a sequence of elements that supports functional operations`, such as filtering, mapping and reducing. It does not store data and does not change the original collection.

A stream has three parts:

- **Source**: Where the elements come from (`list.stream()`, `Arrays.stream(array)`, `Stream.of(...)`).
- **Intermediate operations**: Return a new stream and are lazy, they only run when a terminal operation is called.
- **Terminal operation**: Produces the result and closes the stream.

```java
List<String> names = List.of("Ana", "Bob", "Charlie", "Anna");

List<String> result = names.stream()
                           .filter(name -> name.startsWith("A"))
                           .map(String::toUpperCase)
                           .sorted()
                           .toList();

System.out.println(result); // Output: [ANA, ANNA]
```

## Intermediate operations

- `filter(Predicate)`: Keeps the elements that pass a condition.
- `map(Function)`: Transforms each element.
- `flatMap(Function)`: Transforms each element in a stream and joins them all in one.
- `sorted()`: Sorts the elements (natural order or Comparator).
- `distinct()`: Removes duplicates.
- `limit(n)`: Keeps the first n elements.
- `skip(n)`: Skips the first n elements.

## Terminal operations

- `toList()`: Returns an unmodifiable List (Java 16+).
- `collect(Collector)`: Accumulates the elements in a collection or other result.
- `forEach(Consumer)`: Runs an action for each element.
- `reduce(identity, BinaryOperator)`: Accumulates all elements into a single value.
- `count()`: Returns the number of elements.
- `anyMatch(Predicate)`, `allMatch(Predicate)`, `noneMatch(Predicate)`: Check a condition.
- `findFirst()`: Returns an Optional with the first element.

```java
List<Integer> numbers = List.of(1, 2, 3, 4, 5);

int sum = numbers.stream().reduce(0, Integer::sum);
System.out.println(sum); // Output: 15

long evens = numbers.stream().filter(n -> n % 2 == 0).count();
System.out.println(evens); // Output: 2
```

## Collectors

```java
List<String> names = List.of("Ana", "Bob", "Charlie");

//Join in a String
String joined = names.stream().collect(Collectors.joining(", "));
System.out.println(joined); // Output: Ana, Bob, Charlie

//Group by a key
Map<Integer, List<String>> byLength = names.stream()
                                           .collect(Collectors.groupingBy(String::length));
System.out.println(byLength); // Output: {3=[Ana, Bob], 7=[Charlie]}
```

## OBS

A stream can only be consumed once. To iterate again, create a new stream.
