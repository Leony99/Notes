# Lambda

## Lambda Expressions

It is `an anonymous function that implements the single abstract method of a functional interface` in Java. It can be created inline, passed as a parameter, stored in variables, or returned from methods, representing an executable code block.

* Before Lambda:

To implement interfaces like `Runnable` or `Comparator`, you used anonymous classes.

```java
Runnable tarefa = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
};
```

* Lambda:

```java
//Assigning to a variable of a functional interface type

//FunctionalInterface 'name' = (parameters) -> { expression body }
Runnable tarefa = () -> System.out.println("Hello World!");

new Thread(tarefa).start();
```

```java
//Passing as an argument to a method that expects a functional interface
//The Thread constructor expects a Runnable, so the lambda is inferred as such

//(parameters) -> { expression body }
new Thread(() -> System.out.println("Hello World!")).start();
```

```java
//Using an explicit cast

//Object 'name' = (FunctionalInterface) (parameters) -> { expression body }
Object obj = (Runnable) () -> System.out.println("Hello World!");

new Thread((Runnable) obj).start();
```
