# JavaScript

JavaScript is the programming language of the web. It runs in the browser and, with Node.js, on the server.

<a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript" target="_blank">JavaScript Documentation</a>

## Run

**Browser:** Link the script in the HTML, or use the console of the DevTools (F12).

```html
<script defer src="script.js"></script>
```

**Node.js:**

```console
node script.js
```

## Core concepts

- **Dynamic typing**: The type belongs to the value, not to the variable.
- **Primitive and reference types**: Primitives are copied by value, objects and arrays by reference.
- **Scope**: Where a variable is visible (global, function or block).
- **Closure**: A function remembers the variables of where it was created.
- **Prototype**: The mechanism of inheritance between objects.
- **Event loop**: Runs asynchronous code in a single thread.
