# Operators

## Assignment operators

```javascript
let x;

x = 10
x += 2; //x = x + 2
x -= 2; //x = x - 2
x *= 2; //x = x * 2
x /= 2; //x = x / 2
x **= 2;//x = x ** 2
x %= 2; //x = x % 2
```

## Arithmetic operators

```javascript
x = 2 + 2;
x = 2 - 2;
x = 2 * 2;
x = 2 / 2;
x = 2 ** 2; //Exponentiation
x = 2 % 2; //Division remainder

//Increment operators
x++; //i = i+1 / post-increment
++x; //i = i+1 / pre-increment

//Decrement operators
x--; //i = i-1 / post-decrement
--x; //i = i-1 / pre-decrement
```

## Comparison operators

Return a boolean value.

```javascript
console.log(x == 10); //equal value
console.log(x === 10); //equal value and equal type
console.log(x != 10); //not equal value
console.log(x !== 10); //not equal value or not equal type
console.log(x > 10); //higher
console.log(x >= 10); //higher or equal
console.log(x < 10); //lower
console.log(x <= 10); //lower or equal
```

OBS: Prefer `===` and `!==`. `==` converts the types before comparing, so `"10" == 10` is true.

## Logical operators

Return a boolean value.

```javascript
let a = true, b = false;

console.log(a && b); //a AND b
console.log(a || b); //a OR b
console.log(!a); //Not a
```
