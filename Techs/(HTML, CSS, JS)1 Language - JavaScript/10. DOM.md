# DOM

The DOM (Document Object Model) is the representation of the HTML as objects, which JavaScript can read and change.

The examples use this HTML:

```html
<script defer src="script.js"></script>

<div id="div">
    <title>Lorem, ipsum.</title>
    <p class="Paragraph" id="Paragraph">Lorem ipsum dolor sit amet.</p>
    <p class="Paragraph" id="Paragraph">Lorem ipsum dolor sit amet, consectetur adipisicing elit.</p>
</div>
```

OBS: `defer` waits for the HTML to load, otherwise the script would not find the elements.

## Element selection

**getElement** (only the first referenced element) / **getElements** (all referenced elements):

```javascript
const p1 = document.getElementById("Paragraph");
const p1p2 = document.getElementsByClassName("Paragraph");
```

**querySelector** (only the first referenced element):

```javascript
const pTag = document.querySelector("p");
const pID = document.querySelector("#Paragraph");
const pClass = document.querySelector(".Paragraph");
const pCombinator = document.querySelector("div .Paragraph");
```

**querySelectorAll** (all referenced elements):

```javascript
const pTags = document.querySelectorAll("p");
const pIds = document.querySelectorAll("#Paragraph");
const pClasses = document.querySelectorAll(".Paragraph");
const pCombinators = document.querySelectorAll("div .Paragraph");
```

**Children elements:**

```javascript
const div = document.querySelector("#div");
const divTitle = div.children[0];
const divP1 = div.children[1];
const divFirst = div.firstElementChild;
const divLast = div.lastElementChild;
```

## Element manipulation

```javascript
const div = document.querySelector("#div");

//Alter
div.children[0].textContent = "Title";
div.children[1].innerHTML = "Paragraph<br/>Paragraph"

//Style
div.style.background = "black";
div.children[1].style.color = "grey";

//Remove
div.lastElementChild.remove();
```

## Events

**addEventListener(action, function(event) {})**

- 'action' parameter = The event action.
- 'function(event) {}' = The function called in the event.
- 'event' parameter = Return everything that happened in the event (optional).

```html
<label>Mail:</label>
<input id="mailInput" type="text">

<label>Password:</label>
<input id="passwordInput" type="password">

<button id="submitBtn" type="submit">submit</button>
```

```javascript
const submitBtn = document.querySelector("#submitBtn");
const mailInput = document.querySelector("#mailInput");
const passwordInput = document.querySelector("#passwordInput");

//click
submitBtn.addEventListener("click", function() {
    if(mailInput.value === "" || passwordInput.value === "") {
        alert("Please, fill out the fields!");
        return;
    };

    alert("Logged in as " + mailInput.value);
});

//change
mailInput.addEventListener("change", function(event) {
    console.log(event);
});
```

**Event functions:**

`preventDefault()` - The default action that belongs to the event will not occur.

```javascript
submitBtn.addEventListener("click", function(event) {
    event.preventDefault();
});
```
