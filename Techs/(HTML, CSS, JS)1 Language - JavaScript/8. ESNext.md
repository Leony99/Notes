# ESNext

## Rest and Spread

**Rest** - Transform several individual elements into an array. You can only use it in the last parameter in a function.

```javascript
function toArray(...numbers) {
  return numbers;
}
console.log(toArray(3, 4, 5, 6));
```

**Spread** - Transform a data set (array, object) into individual elements.

```javascript
//Arrays
const numbers = [1, 2, 3, 4, 5];
const moreNumbers = [0, ...numbers, 6];
console.log(moreNumbers);

//Arrays(Character)
const string = "Hello world";
const letters = [...string];
console.log(letters);

//Objects
const dog = {name: "Rex", race: "Bulldog"};
const moreDog = {...dog, color: "white"};
console.log(moreDog);
```

## Promises

A Promise is an object that represents the future result of an asynchronous operation.

States: pending, fulfilled (resolve), rejected (reject).

```javascript
function getUser(id) {
    return new Promise(function(resolve, reject) {
        setTimeout(function() {
            if (id > 0) {
                resolve({id: id, name: "Joseph"});
            }
            else {
                reject(new Error("Invalid id"));
            }
        }, 1000);
    });
}
```

- `then`: Called when the Promise is fulfilled.
- `catch`: Called when the Promise is rejected.
- `finally`: Always called at the end.

```javascript
getUser(1)
    .then(function(user) {
        console.log(user);
    })
    .catch(function(error) {
        console.error(error.message);
    })
    .finally(function() {
        console.log("Finished");
    });
```

## Async/await

Syntactic sugar over Promises.

- `async`: The function always returns a Promise.
- `await`: Waits for the Promise, can only be used inside an async function.

```javascript
async function showUser(id) {
    try {
        const user = await getUser(id);
        console.log(user);
    }
    catch (error) {
        console.error(error.message);
    }
}
showUser(1);
```

## Promise methods

- `Promise.all`: Waits for all Promises, rejects if any of them rejects.
- `Promise.allSettled`: Waits for all Promises, never rejects.
- `Promise.race`: Returns the first Promise to finish.

```javascript
async function showUsers() {
    const users = await Promise.all([getUser(1), getUser(2)]);
    console.log(users);
}
showUsers();
```

## ES Modules

Each file is a module.

```html
<script type="module" src="script.js"></script>
```

**Export:**

```javascript
//Named export - A module can have several
export const PI = 3.14;
export function sum(a, b) {
    return a + b;
}

//Default export - A module can have only one
export default function subtract(a, b) {
    return a - b;
}
```

**Import:**

```javascript
//Named import - The name must be the same as the export
import { PI, sum } from "./math.js";

//Named import with alias
import { sum as add } from "./math.js";

//Default import - The name can be anything
import subtract from "./math.js";

//Import everything as an object
import * as math from "./math.js";

//Dynamic import - Returns a Promise, the module is loaded only when needed
const module = await import("./math.js");
```
