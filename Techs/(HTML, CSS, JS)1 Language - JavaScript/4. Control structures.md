# Control structures

## Conditional structures

**If statement:**

```javascript
let gender = "Male", age = 17;

if (gender == "Male" && age >= 18) {
    console.log("Adult male");
}
else if (gender == "Female" && age >=18) {
    console.log("Adult female");
}
else if (gender == "Male" && age < 18) {
    console.log("Non adult male");
}
else if (gender == "Female" && age < 18) {
    console.log("Non adult female");
}
else {
    console.log("Error");
}
```

**Ternary operator** - Enhanced if.

```javascript
//expression ? IfExpressionTrueDo : IfExpressionFalseDo
let adultOrNot = age >= 18 ? "Adult" : "Non adult";
console.log(adultOrNot)
```

**Switch statement** - Used only with a single value (gender).

```javascript
switch (gender) {
    case "Male":
        console.log("Male");
        break;
    case "Female":
        console.log("Female");
        break;
    default:
        console.log("Error");
}
```

## Repetition structures

```javascript
const numbers = [1, 2.3, 4.4, 6, 10, 11.3];
let count = 0;
```

**For loop:**

```javascript
//For each (value of 'i' starting from 'zero'; while 'i < x'; do 'i++') and do {}
for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}
```

**For in loop:**

```javascript
//For each (value called 'n' in 'numbers') do
for (let n in numbers) {
    console.log(numbers[n]);
}
```

**For of loop:**

```javascript
//For each (element of 'numbers') do
for (const n of numbers) {
    console.log(n);
}
```

**While loop:**

```javascript
//While (true) do {}
while (count <= 3) {
    console.log(count);
    count++;
}
```

**Do while loop:**

```javascript
//Do {} at least once, while (true)
do {
    console.log(count);
    count++;
}
while (count <=3);
```

## Break and continue

```javascript
//Break - stop and get out of the loop
for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] % 2 != 0) {
        break;
    }
    console.log(numbers[i]);
}

//Continue - skip to the next iteration of the loop
for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] % 2 != 0) {
        continue;
    }
    console.log(numbers[i]);
}
```
