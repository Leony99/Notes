# Variables and types

## Variable declaration

- `var`: Global scope if declared outside a function.
- `let`: Block scope if declared inside a block.
- `const`: Block scope if declared inside a block. Can't be reassigned.

```javascript
var a;
let b;
const PI = 3.14;
```

OBS: All variables have function scope if declared inside a function.

## Primitive types

```javascript
//Number
let number = 6;
//Boolean
let bool = true;
//String
let string = "abc";
//Undefined
let notAssigned;
//Null
let empty = null;
```

String methods:

```javascript
string.toLowerCase();
string.toUpperCase();
```

## Reference types

**Objects:**

```javascript
let car = {type:"Fiat", model:"500", color:"white"};
const car2 = {type:"Corvette", model:"Stingray", color:"Red"};

//You can change a property in variable and constant:
car.color = "Black";
car2.color = "White";

//You can add a property in variable and constant:
car.owner = "Leony";
car2.owner = "Leony";

//You can reassign only in variable:
car = {type:"Ferrari", model:"812", color:"red"};
```

**Arrays:**

```javascript
let cars = ["Ferrari", "Corvette" , "Jaguar"];
const cars2 = ["Ferrari", "Corvette" , "Jaguar"];

//You can change an element in variable and constant:
cars[2] = "Porsche";
cars2[2] = "Porsche";

//You can add an element in variable and constant:
cars.push("Volvo");
cars2.push("Volvo");

//You can reassign only in variable:
cars = ["Porsche", "Audi" , "BMW"];
```

**Functions:**

```javascript
let doSomething = function (param1, param2) {
    return param1 + param2;
}
const doSomething2 = function (param1, param2) {
    return param1 - param2;
}
```

## Built in objects

```javascript
//Math - has no constructor
const PI = Math.PI;

//Date
const date = new Date();

//Intl
const formatting = new Intl.NumberFormat();
```
