# Inputs and outputs

## Inputs

```javascript
//Browser dialog input
//prompt returns a string (or null if canceled)
let name = prompt("Name:");
//confirm returns a boolean
let accepted = confirm("Do you accept?");

//HTML element input
let mail = document.getElementById("ID").value;

//Convert an input to number
let age = Number(prompt("Age:"));
```

## Outputs

```javascript
const WORD = "World";

//Console output
console.log("Hello");

//Console formatting output
console.log(`Hello ${WORD}!`);

//HTML element output
document.getElementById("ID").innerHTML = "abc";
```
