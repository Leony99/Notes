# Cheat sheet

Quick reference of the most used JavaScript features.

## Arrays

| Method | What it does |
|---|---|
| `push()`, `pop()` | Add/remove at the end |
| `forEach(fn)` | Runs a function for each element |
| `map(fn)` | New array with transformed elements |
| `filter(fn)` | New array with the elements that pass a test |
| `reduce(fn, initial)` | Accumulates in a single value |
| `find(fn)`, `findIndex(fn)` | First element that passes a test |
| `includes(value)` | Checks if a value exists |
| `concat(array)` | Joins arrays |

## Objects

| Method | What it does |
|---|---|
| `Object.keys(obj)` | Array with the keys |
| `Object.values(obj)` | Array with the values |
| `Object.entries(obj)` | Array with keys and values |
| `Object.freeze(obj)` | Prevents changes |
| `Object.create(proto)` | New object with a prototype |

## DOM

| Method | What it does |
|---|---|
| `document.querySelector('x')` | First matching element |
| `document.querySelectorAll('x')` | All matching elements |
| `element.textContent`, `element.innerHTML` | Content |
| `element.style.color` | Style |
| `element.addEventListener('click', fn)` | Event |
| `element.remove()` | Removes the element |

## Others

| Syntax | What it does |
|---|---|
| `` `Hello ${name}` `` | Template string |
| `const {a, b} = obj` | Object destructuring |
| `const [a, b] = array` | Array destructuring |
| `...array` | Spread |
| `JSON.stringify(x)`, `JSON.parse(x)` | Object to JSON, JSON to object |
| `await fetch(url)` | Request |
