# Tags

A tag is a fixed name for a specific commit, usually used to mark a version. Unlike a branch, it does not move.

- **Annotated**: Stores author, date and message. Used for releases.
- **Lightweight**: Only a name pointing to a commit.

*Example:*

```console
git tag -a v1.0.0 -m "first release"
git tag v1.0.0-beta
git tag -a v0.9.0 'hash'
```

## Semantic versioning

**MAJOR.MINOR.PATCH**

- MAJOR = incompatible changes
- MINOR = new features, compatible
- PATCH = bug fixes, compatible

## Send

`git push` does not send tags, you need to send them explicitly.

*Example:*

```console
git push origin v1.0.0
git push origin --tags
```

## Manage

*Example:*

```console
git tag
git show v1.0.0
git tag -d v1.0.0
git push origin --delete v1.0.0
```

OBS: `git tag -d` only deletes the local tag. The remote one needs its own command.
