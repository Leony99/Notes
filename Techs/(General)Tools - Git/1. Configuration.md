# Configuration

Git keeps its settings in three levels. The most specific level wins.

- **--system**: For all users of the machine.
- **--global**: For your user, in the `~/.gitconfig` file.
- **--local**: For the current repository, in the `.git/config` file (default).

## Identity

Name and e-mail are written in every commit.

*Example:*

```console
git config --global user.name "John Doe"
git config --global user.email "john@example.com"
```

## Other settings

*Example:*

```console
git config --global init.defaultBranch main
git config --global core.editor "code --wait"
git config --global core.autocrlf true
```

OBS: Use `core.autocrlf true` on Windows and `input` on Linux/Mac, so line endings do not show up as changes.

## Check settings

*Example:*

```console
git config --list
git config user.name
```

## SSH key

An SSH key authenticates you on GitHub without typing a password.

- Generate the keys. The `.pub` file is the public one, the other must never be shared.
- Start the ssh-agent and add the private key to it.
- Add the content of the `.pub` file in GitHub → Settings → SSH and GPG keys.
- Test the connection.

*Example:*

```console
ssh-keygen -t ed25519 -C "john@example.com"
eval $(ssh-agent -s)
ssh-add ~/.ssh/id_ed25519
ssh -T git@github.com
```

## Alias

Shortcuts for long commands.

*Example:*

```console
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all"
```

```console
git st
git lg
```
