# Commands

Quick reference of the Git commands, by category.

## 1. Comandos de autenticação

| Comando | O que faz |
|---|---|
| `ssh-keygen -t ed25519 -C 'e-mail'` | Gerar chaves ssh |
| `eval $(ssh-agent -s)` | Executar ssh-agent |
| `ssh-add 'arquivo chave privada'` | Adicionar chave privada ssh ao ssh-agent |
| `git config --global user.name 'nome'` | Configurar nome |
| `git config --global --replace-all user.name 'nome'` | Editar nome |
| `git config user.name` | Mostrar nome |
| `git config --global user.email 'e-mail'` | Configurar e-mail |
| `git config --global --replace-all user.email 'e-mail'` | Editar e-mail |
| `git config user.email` | Mostrar e-mail |
| `git config --list` | Mostrar informações |
| `git config --global ‘wichInfo’ ‘info’`<br>`git config --global --replace-all ‘wichInfo’ ' info'`<br>`git config ‘wichInfo’` | Configurar/editar/mostrar informações do --list |

## 2. Comandos de diretório

| Comando | O que faz |
|---|---|
| `cd 'caminho do diretório'` | Navegar para diretório específico |
| `cd /` | Navegar para Disco Local |
| `cd 'x'` | Avançar para diretório x |
| `cd ..` | Voltar diretório |
| `pwd` | Mostrar caminho do diretório atual |
| `dir` ou `ls` | Mostar conteúdo no diretório atual |
| `dir -a` ou `ls -a` | Mostrar conteúdo oculto no diretório atual |
| `mkdir 'nomedapasta'` | Criar diretório |
| `rmdir 'nomedapasta'` | Excluir diretório vazio |
| `rmdir 'nomedapasta' /S /Q` | Excluir diretório |

## 3. Comandos do repositório local

| Comando | O que faz |
|---|---|
| `git init` | Iniciar repositório local na pasta selecionada |
| `git status` | Ver status do repositório local |

## 4. Comandos para versionamento do repositório local

| Comando | O que faz |
|---|---|
| `git add *` | 'Rastrear' todos arquivos no repositório atual |
| `git add 'nomedoarquivo'` | 'Rastrear' arquivo |
| `git rm --cached 'nomedoarquivo'` | 'Desrastrear' arquivo |
| `git commit -m 'mensagem'` | 'Commitar' repositório |

## 5. Comandos do repositório remoto

| Comando | O que faz |
|---|---|
| `git remote add 'nomedorepositório' 'linkdorepositório'` | Ligar repositório local com repositório remoto |
| `git remote` | Mostrar repositórios remotos |
| `git remote -v` | Mostrar link dos repositórios remotos |
| `git remote show 'nomedorepositórioremoto'` | Ver mais informação sobre algum remoto |
| `git remote rename 'nomeantigo' 'novonome'` | Renomear remoto |
| `git remote rm 'nomedorepositórioremoto'` | Excluir remoto |

## 6. Comandos para versionamento do repositório remoto

| Comando | O que faz |
|---|---|
| `git push 'nomedorepositório' 'ramificaçãoenviada'` | Enviar ramificação local para repositório remoto |
| `git pull 'nomedorepositório' 'ramificaçãoareceber'` | Receber ramificação remota em repositório local |

## 7. Outros

| Comando | O que faz |
|---|---|
| `git clone 'linkdorepositório'` | Clonar repositório remoto |

---

| Comando | O que faz |
|---|---|
| `git diff --name-only` | Mostrar nome de arquivos que foram alterados |
| `git diff` | Mostrar alterações em arquivos |
| `git commit -am "'mensagem'"` | Commitar modificação sem passar para staged |
| `git checkout 'nomedoarquivo'` ou `git checkout -- 'nomedoarquivo'` | Desfazer modificação em 'arquivo' |
| `git reset HEAD 'nomedoarquivo'` | Tirar modificação no 'arquivo' do staged |

---

| Comando | O que faz |
|---|---|
| `git shortlog -sn` | Mostrar quantidade de commits |
| `git shortlog` | Mostrar quantidade de commits e quais os commits |
| `git log` ou `git log --decorate`(mais informações) | Mostrar histórico de commits(log) |
| `git log --author="'nomedapessoa'"` | Mostrar histórico de commits(log) de uma pessoa |
| `git log --graph` | Mostrar histórico de commits(log) em gráficos |
| `git show 'hashdocommit'` | Mostrar as alterações de um certo commit |

---

| Comando | O que faz |
|---|---|
| `git reset --soft 'hashdocommitanterioraodesejado'` | Voltar commit para staged |
| `git reset --mixed 'hashdocommitanterioraodesejado'` | Voltar commit para Modified/untracked |
| `git reset --hard 'hashdocommitanterioraodesejado'` | Excluir o commit |
| `git revert 'hashdocommit'` | Criar novo commit, revertendo a alteração de um commit |

---

| Comando | O que faz |
|---|---|
| `git stash` | Criar um stash para guardar uma alteração de arquivo |
| `git stash apply` | Pegar mudanças guardadas |
| `git stash list` | Mostrar lista de stashes |
| `git stash clear` | Limpar stashes |

---

| Comando | O que faz |
|---|---|
| `git checkout -b 'nomedobranch'` | Criar branch |
| `git branch -D 'nomedobranch'` | Excluir branch |
| `git branch` | Mostrar branchs |
| `git branch -v` | Mostrar o último commit em cada branch |
| `git checkout 'nomedobranch'` | Mudar de branch |
| `git merge 'nomedobranch'` | Juntar commits de um branch com o branch selecionado(merge) |
| `git rebase 'nomedobranch'` | Juntar commits de um branch com o branch selecionado(rebase) |
| `git branch --merged` | Ver quais branches já foram mesclados no branch que você está |
| `git branch --no-merged` | Ver todos os branches que contém trabalho que você ainda não fez o merge |

---

| Comando | O que faz |
|---|---|
| `git push -u 'paraondevai' 'deondevem'` | Enviar arquivos de branch para repositório remoto |

---

| Comando | O que faz |
|---|---|
| `git clone 'linksshdorepositório' 'nomedapasta'` | Copiar um repositório remoto |

---

| Comando | O que faz |
|---|---|
| `git tag -a 'versão/nome' -m 'mensagem'` | Criar tag |
| `git tag -a 'versão/nome' 'hashdocommit'` | Criar tag em commits antigos |
| `git tag -d 'versão/nome'` | Excluir tag |
| `git push 'paraondevai' 'versão/nome'` | Upar uma tag para repositório remoto |
| `git push 'paraondevai' --tags` | Upar tags para repositório remoto |
| `git push 'paraondevai' 'deondevem' --tags` | Upar tags de branch para repositório remoto |
| `git tag` | Mostrar lista de tags |
| `git show 'versão/nome'` | Mostrar dados da tag junto com o commit que foi tagueado |

---

| Comando | O que faz |
|---|---|
| `git push 'nomedorepositório' :'versão/nome'` | Excluir tag remoto |
| `git push 'nomedorepositório' :'nomedobranch'` | Excluir branch remoto |
