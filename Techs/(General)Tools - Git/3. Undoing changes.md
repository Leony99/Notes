# Undoing changes

The right command depends on where the change is, and on whether it was already sent to the remote.

| Situation | Command |
|---|---|
| Discard a modified file | `git restore 'file'` |
| Remove a file from staged | `git restore --staged 'file'` |
| Fix the last commit | `git commit --amend` |
| Undo local commits | `git reset` |
| Undo a commit already pushed | `git revert` |
| Save changes for later | `git stash` |

OBS: `git restore` is the modern form of `git checkout -- 'file'` and `git reset HEAD 'file'`.

## Amend

Replaces the last commit, to change its message or add a forgotten file.

*Example:*

```console
git add forgotten-file.txt
git commit --amend -m "new message"
```

## Reset

Moves the current branch to another commit. The mode decides what happens to the changes of the removed commits.

- **--soft**: The changes go back to staged.
- **--mixed**: The changes go back to modified (default).
- **--hard**: The changes are deleted.

*Example:*

```console
git reset --soft HEAD~1
git reset --mixed HEAD~1
git reset --hard HEAD~1
```

OBS: `HEAD~1` is the commit before the current one. Reset receives the commit to go back to, not the commit to remove.

OBS: `git reset --hard` deletes uncommitted changes permanently.

## Revert

Creates a new commit that undoes the changes of another commit. The history is kept, so it is the safe way to undo something already pushed.

*Example:*

```console
git revert 'hash'
```

OBS: Use `reset` only for local commits. Resetting pushed commits rewrites the history that other people already have.

## Stash

Saves your changes in a temporary stack and cleans the working directory. Useful when you need to change branches in the middle of something.

*Example:*

```console
git stash
git stash -u
git stash list
git stash apply
git stash pop
git stash clear
```

OBS: `-u` includes untracked files. `apply` keeps the stash in the list, `pop` removes it.

## Reflog

Records every movement of HEAD, including commits removed by a reset. It is the way to recover something lost.

*Example:*

```console
git reflog
git reset --hard 'hash'
```

OBS: Reflog is local and only finds what was committed. Changes that were never committed cannot be recovered.
