# Commands

Quick reference of the most used Next.js commands.

| Command | What it does |
|---|---|
| `npx create-next-app@latest` | Creates a project |
| `npm run dev` | Starts the dev server (`next dev`) |
| `npm run build` | Generates the production build (`next build`) |
| `npm run start` | Serves the production build (`next start`) |
| `npm run lint` | Runs the linter |
| `npx @next/codemod@canary upgrade latest` | Upgrades Next.js and applies the codemods |

## File conventions

| File | What it does |
|---|---|
| `page.jsx` | Route interface |
| `layout.jsx` | Shared layout |
| `loading.jsx` | Loading state |
| `error.jsx` | Error state |
| `not-found.jsx` | Not found page |
| `route.ts` | API endpoint |
| `proxy.ts` | Code before the requests |

## Folder conventions

| Folder | Route |
|---|---|
| `app/about/` | `/about` |
| `app/post/[id]/` | `/post/1` |
| `app/shop/[...slug]/` | `/shop/a/b/c` |
| `app/(group)/about/` | `/about` |
