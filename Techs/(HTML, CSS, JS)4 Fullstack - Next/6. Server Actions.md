# Server Actions

Server Actions are async functions that run on the server and can be called directly from forms and components, without creating an API route.

Mark the function or the file with `'use server'`.

*Example:*

```jsx
// app/actions.js
'use server'

import { revalidatePath } from 'next/cache';

export async function createPost(formData) {
  const title = formData.get('title');

  await db.post.create({ data: { title } });
  revalidatePath('/posts');
}
```

```jsx
// app/posts/new/page.jsx
import { createPost } from '../../actions';

export default function NewPost() {
  return (
    <form action={createPost}>
      <input name="title" />
      <button type="submit">Save</button>
    </form>
  );
}
```

OBS: `revalidatePath` updates the cached data of a route after a change.

OBS: A Server Action is a public endpoint. Check authentication and validate the data inside the function.
