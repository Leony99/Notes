# Plugins

Plugins do tasks that loaders can't, over the whole build. They are instantiated in the `plugins` list.

## MiniCssExtractPlugin

Extracts the CSS to its own file, instead of putting it inside the JS.

*Example:*

```javascript
const miniCssExtractPlugin = require('mini-css-extract-plugin');

module.exports = {
    plugins: [
        new miniCssExtractPlugin({
            filename: 'style.css' //.css generated file name
        })
    ]
};
```

## CopyWebpackPlugin

Copies files to the output folder.

*Example:*

```javascript
const copyPlugin = require('copy-webpack-plugin');

module.exports = {
    plugins: [
        new copyPlugin({
            patterns: [
                {
                    context: 'src', //The directory for resolving 'from'
                    from: '**/*.html', //Copy all .html files and folders structure
                    noErrorOnMissing: true
                },
                {
                    context: 'src',
                    from: './assets', //Copy /assets files
                    to: './assets', //Copy to /assets folder in generated files path
                    noErrorOnMissing: true
                }
            ]
        })
    ]
};
```

## HtmlWebpackPlugin

Generates an HTML file with the generated scripts and styles already linked.

*Example:*

```javascript
const HtmlWebpackPlugin = require('html-webpack-plugin');

module.exports = {
    plugins: [
        new HtmlWebpackPlugin({ template: './src/index.html' })
    ]
};
```
