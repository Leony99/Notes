# Loaders

Loaders transform files so they can be imported. They are declared in `module.rules`.

- `test`: A regex with the files the rule applies to.
- `use`: The loaders to run.

OBS: Loaders run from the last to the first of the list.

## CSS

*Example:*

```console
npm install css-loader mini-css-extract-plugin --save-dev
```

```javascript
const miniCssExtractPlugin = require('mini-css-extract-plugin');

module.exports = {
    module: {
        rules: [
            {
                test: /\.css$/,
                use: [
                    miniCssExtractPlugin.loader, //Add .css to .css generated file
                    'css-loader' //Read imports, urls, etc
                ]
            }
        ]
    }
};
```

## Sass

*Example:*

```console
npm install sass sass-loader --save-dev
```

```javascript
{
    test: /\.s[ac]ss$/,
    use: [
        miniCssExtractPlugin.loader, //Add .scss to .css generated file
        'css-loader', //Read imports, urls, etc.
        'sass-loader' //Compile .scss to .css
    ]
}
```

OBS: `node-sass` is deprecated. Use the `sass` package.

## Images

Webpack 5 handles files with Asset Modules, no loader needed.

*Example:*

```javascript
{
    test: /\.(png|svg|jpg|gif)$/,
    type: 'asset/resource'
}
```

OBS: `file-loader` is deprecated in favor of Asset Modules.
