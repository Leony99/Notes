# Dev server

`webpack-dev-server` serves the project in memory and reloads the page on changes, so nothing is written to `dist/`.

## Installation

```console
npm install webpack-dev-server --save-dev
```

## Configuration

*Example:*

```javascript
module.exports = {
    devServer: {
        static: './dist', //Static files to provide
        port: 8080, //Server port
        open: true, //Open the browser
        hot: true //Update modules without a full reload
    }
};
```

```json
{
  "scripts": {
    "dev": "webpack-dev-server"
  }
}
```

OBS: Access `http://localhost:8080`.

## Source maps

Link the generated code to the original files in the browser DevTools.

*Example:*

```javascript
module.exports = {
    devtool: 'source-map'
};
```
