# Commands

Quick reference of the most used Webpack commands.

| Command | What it does |
|---|---|
| `npx webpack` | Runs the build |
| `npx webpack --mode production` | Runs the build in production mode |
| `npx webpack --watch` | Rebuilds on changes |
| `npx webpack --config 'file'` | Uses another config file |
| `npx webpack serve` | Starts the dev server |
| `npm run dev` | Starts the dev server (`dev` script) |
| `npm run prod` | Runs the production build (`prod` script) |
