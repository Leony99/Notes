# Webpack

Webpack is a module bundler. It starts from an entry file, follows every `import` and generates optimized files for the browser.

<a href="https://webpack.js.org/concepts/" target="_blank">Webpack Documentation</a>

## Installation

```console
npm install webpack webpack-cli --save-dev
```

## Core concepts

- **Entry**: The module that starts the dependencies list.
- **Output**: Where the generated files are saved, and their names.
- **Loaders**: Teach Webpack to read files that are not JavaScript (CSS, Sass, images).
- **Plugins**: Do tasks over the whole build (extract CSS, copy files, minimize).
- **Mode**: `development` or `production`. Enables the built-in optimizations.
- **Dependency graph**: The map of all modules connected by imports.

## Basic flow

```
src/index.js ──▶ imports (.js, .css, images) ──▶ loaders + plugins ──▶ dist/
```

## Project structure

- `src/`: The source files.
- `dist/`: The generated files, also the folder to deploy.
- `webpack.config.js`: The configuration.

The entry file imports the CSS and JS files.

```javascript
// src/index.js
import './css/style.css';
import './css/style2.css';
import './js/script.js';
import './js/script2.js';
```

The HTML links the generated files.

```html
<link rel="stylesheet" href="style.css">
<script defer src="script.js"></script>
```

OBS: Add `node_modules` to `.gitignore`.

OBS: For new projects, Vite is the most common choice today. Webpack is still common in existing projects.
