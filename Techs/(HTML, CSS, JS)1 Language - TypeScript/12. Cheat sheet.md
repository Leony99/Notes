# Cheat sheet

Quick reference of the most used TypeScript features.

## Types

| Syntax | What it does |
|---|---|
| `string`, `number`, `boolean` | Primitive types |
| `string[]`, `Array<string>` | Array |
| `[string, number]` | Tuple |
| `string \| number` | Union |
| `A & B` | Intersection |
| `"a" \| "b"` | Literal types |
| `unknown` | Any value, must be narrowed |
| `any` | Turns off the checks |
| `never` | A value that can't exist |
| `void` | No return |

## Objects

| Syntax | What it does |
|---|---|
| `type User = {}` | Type alias |
| `interface User {}` | Interface |
| `name?: string` | Optional property |
| `readonly id: number` | Readonly property |
| `interface B extends A` | Extends an interface |

## Generics and operators

| Syntax | What it does |
|---|---|
| `function fn<T>(x: T): T` | Generic function |
| `<T extends Base>` | Generic constraint |
| `keyof T` | Keys of a type |
| `typeof value` | Type of a value |
| `T["key"]` | Type of a property |
| `value as Type` | Type assertion |
| `value as const` | Literal and readonly |
| `value satisfies Type` | Checks without changing the type |
| `value!` | Says the value is not null |

## Utility types

| Type | What it does |
|---|---|
| `Partial<T>`, `Required<T>` | All optional, all required |
| `Readonly<T>` | All readonly |
| `Pick<T, K>`, `Omit<T, K>` | Choose, remove properties |
| `Record<K, V>` | Object from keys and value |
| `Exclude<T, U>`, `Extract<T, U>` | Remove, keep from a union |
| `ReturnType<F>`, `Parameters<F>` | Return, parameters of a function |
| `Awaited<T>` | Value inside a Promise |

## Commands

| Command | What it does |
|---|---|
| `npm install typescript --save-dev` | Install TypeScript |
| `npx tsc --init` | Create tsconfig.json |
| `npx tsc` | Compile the project |
| `npx tsc --watch` | Compile on changes |
| `npx tsc --noEmit` | Only check the types |
| `npx tsx 'file.ts'` | Run a TypeScript file |
