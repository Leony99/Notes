# Advanced types

Types that are built from other types. Most used in libraries and shared code.

## keyof and typeof

- `keyof`: A union with the keys of a type.
- `typeof`: The type of a value.

*Example:*

```typescript
const config = { host: "localhost", port: 3000 };

type Config = typeof config; // { host: string; port: number }
type ConfigKey = keyof Config; // "host" | "port"
```

## Indexed access

Gets the type of a property.

*Example:*

```typescript
type User = { name: string; address: { city: string } };

type City = User["address"]["city"]; // string
```

## Mapped types

Creates a type by going through the keys of another one.

*Example:*

```typescript
type Optional<T> = {
  [K in keyof T]?: T[K];
};

type Flags<T> = {
  [K in keyof T]: boolean;
};

type Features = Flags<{ darkMode: string; beta: string }>;
// { darkMode: boolean; beta: boolean }
```

## Conditional types

**T extends U ? X : Y**

*Example:*

```typescript
type IsString<T> = T extends string ? true : false;

type A = IsString<"a">; // true
type B = IsString<1>; // false
```

**infer:** Captures a type inside the condition.

```typescript
type ElementOf<T> = T extends (infer E)[] ? E : never;

type Item = ElementOf<string[]>; // string
```

## Template literal types

*Example:*

```typescript
type Event = "click" | "focus";
type Handler = `on${Capitalize<Event>}`; // "onClick" | "onFocus"
```
