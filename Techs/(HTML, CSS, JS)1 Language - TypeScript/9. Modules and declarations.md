# Modules and declarations

## Modules

Types are exported and imported like values. `import type` makes it clear the import disappears from the final JavaScript.

*Example:*

```typescript
// types.ts
export interface User {
  name: string;
}
```

```typescript
// index.ts
import type { User } from "./types";

const user: User = { name: "John" };
```

## Declaration files

A `.d.ts` file only describes types, with no code. It is how a JavaScript library gets types.

*Example:*

```typescript
// globals.d.ts
declare const API_URL: string;

declare function track(event: string): void;
```

## @types

Libraries written in JavaScript usually have their types in a separate package.

```console
npm install @types/node --save-dev
npm install @types/express --save-dev
```

OBS: Many libraries already include their types, then no `@types` package is needed.

## Global augmentation

Adds properties to an existing type.

*Example:*

```typescript
declare global {
  interface Window {
    analytics: { track: (event: string) => void };
  }
}

export {};
```

OBS: `export {}` makes the file a module, which `declare global` requires.
