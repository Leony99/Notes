# Utility types

Built-in generic types that create a new type from another one.

The examples use this type:

```typescript
interface User {
  id: number;
  name: string;
  email: string;
  phone?: string;
}
```

## Changing properties

- `Partial<T>`: All properties optional.
- `Required<T>`: All properties required.
- `Readonly<T>`: All properties readonly.

*Example:*

```typescript
interface User {
  id: number;
  name: string;
  phone?: string;
}

function updateUser(id: number, changes: Partial<User>): void {
  console.log(id, changes);
}

updateUser(1, { name: "John" });

const user: Readonly<User> = { id: 1, name: "John" };
const full: Required<User> = { id: 1, name: "John", phone: "123" };
```

## Choosing properties

- `Pick<T, Keys>`: Only the chosen properties.
- `Omit<T, Keys>`: All properties, except the chosen ones.

*Example:*

```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

type UserPreview = Pick<User, "id" | "name">;
type CreateUser = Omit<User, "id">;

const newUser: CreateUser = { name: "John", email: "john@example.com" };
```

## Objects

- `Record<Keys, Value>`: An object with those keys and value type.

*Example:*

```typescript
type Role = "admin" | "user";

const permissions: Record<Role, string[]> = {
  admin: ["read", "write"],
  user: ["read"],
};
```

## Unions

- `Exclude<T, U>`: Removes types from a union.
- `Extract<T, U>`: Keeps only the types of a union.
- `NonNullable<T>`: Removes `null` and `undefined`.

*Example:*

```typescript
type Status = "active" | "inactive" | "deleted";

type Visible = Exclude<Status, "deleted">; // "active" | "inactive"
type Hidden = Extract<Status, "deleted">; // "deleted"
type Name = NonNullable<string | null | undefined>; // string
```

## Functions

- `ReturnType<T>`: The return type of a function.
- `Parameters<T>`: The parameters of a function, as a tuple.
- `Awaited<T>`: The value inside a Promise.

*Example:*

```typescript
async function getUser(id: number) {
  return { id, name: "John" };
}

type Params = Parameters<typeof getUser>; // [id: number]
type UserPromise = ReturnType<typeof getUser>; // Promise<{ id: number; name: string }>
type User = Awaited<UserPromise>; // { id: number; name: string }
```
