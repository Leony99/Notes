# TypeScript

TypeScript is a typed superset of JavaScript that compiles to plain JavaScript.

<a href="https://www.typescriptlang.org/docs/">TypeScript Documentation</a>

## Core concepts

- **Static typing**: Types are checked at compile time, before the code runs.
- **Type inference**: The compiler discovers the type when it is obvious.
- **Compilation**: `tsc` removes the types and generates JavaScript.

OBS: Types only exist at compile time. They do not validate data at runtime.

## Installation

```Console
npm install typescript --save-dev
```

## Commands

Create tsconfig.json file:

```Console
tsc --init
```

Compile all TypeScript files to JavaScript:

```Console
tsc
```

Check the types without generating files:

```Console
tsc --noEmit
```

Compile a TypeScript file to JavaScript:

```Console
tsc 'filename.ts'
```

## tsconfig.json

Important properties:

- **target**: ECMAScript version to compile to
- **module**: Import module format(commonjs, ESNext)
- **rootDir**: Source directory
- **outDir**: Output directory
- **removeComments**: Remove comments from JavaScript output
- **strict**: Enable all the strict type checks
