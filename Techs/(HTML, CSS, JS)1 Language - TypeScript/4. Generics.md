# Generics

Generics in TypeScript are a way to create reusable components, allowing functions, classes, or interfaces to work with different types of data without having to explicitly define which types will be used beforehand.

*Examples:*

```TypeScript
function identity<T>(param: T): T {
  return param;
}

let stringOutput = identity<string>("Hello!");
let numberOutput = identity<number>(100);
```

```TypeScript
function logArray<T>(array: T[]): void {
  array.forEach((element) => console.log(element));
}

logArray<number>([1, 2, 3]);
logArray<string>(["a", "b", "c"]);
```

```TypeScript
class Box<T> {
  constructor(private content: T) {}

  getContent(): T {
    return this.content;
  }
}

const numberBox = new Box<number>(123);
console.log(numberBox.getContent());
```

Generics also can be used to explicitly define the type used in a specific context.

*Examples:*

```typescript
const numberValue = identity<number>(42);
```
```tsx
const [user, setUser] = useState<UserProps|null>(null);
```

## Constraints

`extends` limits the types a generic accepts, so the code can use what the constraint guarantees.

*Example:*

```typescript
function getLength<T extends { length: number }>(item: T): number {
  return item.length;
}

getLength("abc");
getLength([1, 2, 3]);
```

**keyof constraint:** Ensures the key exists in the object.

```typescript
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { name: "John", age: 25 };
getProperty(user, "name"); // string
```

## Multiple and default types

*Example:*

```typescript
function pair<K, V>(key: K, value: V): [K, V] {
  return [key, value];
}

interface ApiResponse<T = unknown> {
  data: T;
  status: number;
}

const response: ApiResponse<string[]> = { data: ["a"], status: 200 };
```

OBS: The type is usually inferred, so `pair("a", 1)` works without writing `<string, number>`.
