# Cheat sheet

Quick reference of the most used Spring Boot features.

## Annotations

| Annotation | What it does |
|---|---|
| `@SpringBootApplication` | Marks the main class |
| `@RestController` | REST controller |
| `@RequestMapping("/path")` | Base path of a controller |
| `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping` | Maps HTTP methods |
| `@PathVariable` | Value from the URL path |
| `@RequestParam` | Value from the query string |
| `@RequestBody` | JSON body to object |
| `@Valid` | Validates the object |
| `@ResponseStatus` | HTTP status of the response |
| `@Service`, `@Repository`, `@Component` | Beans |
| `@Configuration`, `@Bean` | Manual bean definition |
| `@Value("${key}")` | Injects a configuration value |
| `@Transactional` | Runs in a transaction |
| `@Entity`, `@Table`, `@Id`, `@GeneratedValue` | JPA entity |
| `@RestControllerAdvice`, `@ExceptionHandler` | Global error handling |

## Common HTTP responses

| Method | Status |
|---|---|
| `GET` | 200 OK |
| `POST` | 201 Created |
| `PUT`, `PATCH` | 200 OK |
| `DELETE` | 204 No Content |
| Invalid data | 400 Bad Request |
| Not found | 404 Not Found |

## Commands

| Command | What it does |
|---|---|
| `.\mvnw.cmd spring-boot:run` | Runs in development |
| `.\mvnw.cmd test` | Runs the tests |
| `.\mvnw.cmd clean package` | Generates the `.jar` |
| `java -jar target/app.jar` | Runs the `.jar` |
| `java -jar target/app.jar --spring.profiles.active=prod` | Runs with a profile |
