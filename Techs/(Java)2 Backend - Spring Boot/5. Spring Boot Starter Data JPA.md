# Spring Boot Starter Data JPA

`spring-boot-starter-data-jpa` is a starter that adds data persistence with JPA for relational databases, including modules such as spring-data-jpa (for automatic repositories), spring-orm (Hibernate integration), spring-tx (transactions) and hibernate-core (JPA implementation), bringing annotations to map entities, define repositories and manage transactions. It requires a database driver (e.g., MySQL) as an additional dependency.

**Modules included:**

- `spring-boot-starter` and its modules.
- `spring-data-jpa` - Provides automatic repositories and integration with JPA.
- `spring-orm` - Integrates Spring with Hibernate/JPA.
- `spring-tx` - Transaction management.
- `spring-jdbc` - Base for JDBC connections (used by JPA).
- `hibernate-core` - Standard implementation of JPA (Hibernate).
- `jakarta.persistence-api` - JPA API (default specification).
- `jakarta.transaction-api` - Jakarta EE transactions API.

## Annotations

>(spring-context) `@Repository`: Marks an interface as a repository (optional when extending a Spring Data repository).

(spring-data-jpa) `@Query`: Defines a custom query (used in repositories).

(spring-data-commons) `@Param`: Names parameters in @Query queries.

(spring-data-jpa) `@Modifying`: Indicates that a query modifies data (e.g., UPDATE, DELETE).

(spring-data-jpa) `@EnableJpaRepositories`: Activates JPA repositories (usually implicit in @SpringBootApplication).

(spring-tx) `@Transactional`: Defines the transaction scope.

(spring-tx) `@EnableTransactionManagement`: Activates transaction management (usually implicit).

(jakarta.persistence-api) `@PersistenceContext`: Injects an EntityManager.

>(jakarta.persistence-api) `@Entity`: Marks a class as a JPA entity.

>(jakarta.persistence-api) `@Table`: Specifies the table in the database.

>(jakarta.persistence-api) `@Id`: Defines the primary key.

>(jakarta.persistence-api) `@GeneratedValue`: Defines the ID generation strategy.

(jakarta.persistence-api) `@Column`: Maps a database column.

(jakarta.persistence-api) `@ManyToOne`, `@OneToMany`, etc.: Defines relationships between entities.
