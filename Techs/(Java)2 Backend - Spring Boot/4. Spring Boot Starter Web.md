# Spring Boot Starter Web

OBS: From Spring Boot 4.0 this starter is called `spring-boot-starter-webmvc`, and `spring-boot-starter-web` is its old name.

`spring-boot-starter-web` is one of Spring Boot's most popular dependencies, designed to facilitate the development of web applications such as RESTful APIs or complete web applications based on the MVC (Model-View-Controller) pattern. It brings together a set of libraries and automatic settings that allow you to quickly start building HTTP endpoints without having to configure everything manually.

**Modules included:**

- `spring-boot-starter` and its modules.
- `spring-web` - Support for servlets and integration with web technologies.
- `spring-webmvc` - MVC pattern implementation and REST support.
- `spring-boot-starter-tomcat` - Embedded Tomcat server (default, but can be replaced by Jetty).
- `jackson-databind` - Library for JSON serialization/deserialization.

## Annotations

(spring-web) `@ControllerAdvice`: Defines a global exception handler or global settings for controllers.

(spring-web) `@ResponseBody`: Indicates that the return is serialized directly (used in @Controller).

(spring-context) `@Controller`: Marks a class as an MVC controller.

>(spring-web) `@RestController`: Marks a class as a REST controller, combining @Controller and @ResponseBody, where all methods return data (e.g., JSON) directly, without rendering views.

>(spring-web) `@RequestMapping(value)`: Maps URLs to controller methods.

>(spring-web) `@GetMapping`: Maps HTTP GET requests to a specific method.

>(spring-web) `@PostMapping`: Maps HTTP POST requests to a specific method.

>(spring-web) `@PutMapping`: Maps HTTP PUT requests to a specific method.

>(spring-web) `@PatchMapping`: Maps HTTP PATCH requests to a specific method.

>(spring-web) `@DeleteMapping`: Maps HTTP DELETE requests to a specific method.

>(spring-web) `@PathVariable`: Extracts values of path variables in the URL.

>(spring-web) `@RequestParam`: Extracts parameters from the query string (e.g., ?name=John).

>(spring-web) `@RequestBody`: Converts the body of the request (e.g., JSON) into a Java object.

(spring-web) `@RequestHeader`: Extracts HTTP headers.

(spring-web) `@ModelAttribute`: Binds data to an object or model.

>(spring-web) `@ResponseStatus`: Defines the HTTP status code.

(jackson-annotations) `@JsonProperty`: Defines the property name in JSON.

(jackson-annotations) `@JsonIgnore`: Ignores a property in serialization.

(jackson-annotations) `@JsonInclude`: Controls the inclusion of properties (e.g., ignore nulls).
