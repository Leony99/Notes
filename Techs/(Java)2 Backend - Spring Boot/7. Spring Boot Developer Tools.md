# Spring Boot Developer Tools

`spring-boot-devtools` is an optional Spring Boot dependency designed to improve productivity during development, offering tools such as automatic application restart when it detects code changes, automatic resource reload in the web browser via LiveReload, and settings optimized for the local environment, such as disabling template caches.

It does not add functionality to the application in production, and is usually configured with `<scope>runtime</scope>` and `<optional>true</optional>` in `pom.xml` to avoid its inclusion in final builds.
