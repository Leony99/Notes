# Configuration

Spring Boot reads its settings from `src/main/resources/application.properties` (or `application.yml`).

*Example:*

```properties
server.port=8080

spring.datasource.url=jdbc:postgresql://localhost:5432/app
spring.datasource.username=${DB_USER}
spring.datasource.password=${DB_PASSWORD}

spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=true
```

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/app
    username: ${DB_USER}
    password: ${DB_PASSWORD}
```

OBS: `${VAR}` reads an environment variable. Never commit passwords in this file.

## ddl-auto

Defines what Hibernate does with the tables when the application starts.

- none = does nothing
- validate = checks if the tables match the entities
- update = changes the tables to match the entities
- create = recreates the tables
- create-drop = recreates the tables and drops them at the end

OBS: In production use `validate` or `none`, and manage the schema with a migration tool like Flyway.

## Profiles

Different settings for each environment. The file `application-{profile}.properties` overrides the default one.

*Example:*

```
application.properties
application-dev.properties
application-prod.properties
```

```console
java -jar app.jar --spring.profiles.active=prod
```

## Reading values

**@Value:** Injects one value.

```java
@Value("${app.name}")
private String appName;
```

**@ConfigurationProperties:** Binds a group of values to a class.

```java
@ConfigurationProperties(prefix = "app.mail")
public record MailProperties(String host, int port) {}
```

```java
@SpringBootApplication
@ConfigurationPropertiesScan
public class MyProjectApplication {
}
```
