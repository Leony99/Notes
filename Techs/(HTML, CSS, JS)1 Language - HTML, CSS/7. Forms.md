# Forms

- `<form>`: Set up an input form.
- `<label>`: Label of a field.
- `<input>`: Input form.
- `<select>`: Input form (list type).
- `<option>`: Option in list type.

## Input types

```html
<input type="text">
<input type="password">
<input type="date">
<input type="submit">
```

*Example:*

```html
<form>
    <label>Textarea</label>
    <input type="text" placeholder="Text here">

    <label>Senha</label>
    <input type="password" placeholder="Password here">

    <label>Date</label>
    <input type="date">

    <label>Option</label>
    <select>
        <option value="male">Male</option>
        <option value="female">Female</option>
    </select>

    <input type="submit">
</form>
```
