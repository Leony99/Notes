# Cheat sheet

Quick reference of the most used HTML tags and CSS properties.

## HTML

| Tag | What it does |
|---|---|
| `<h1>` to `<h6>` | Headings |
| `<p>`, `<br/>`, `<hr/>` | Paragraph, line break, horizontal line |
| `<div>`, `<span>` | Generic block, generic inline |
| `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` | Semantic sections |
| `<a href="">` | Link |
| `<img src="" alt="">` | Image |
| `<ul>`, `<ol>`, `<li>` | Lists |
| `<table>`, `<tr>`, `<th>`, `<td>` | Table |
| `<form>`, `<label>`, `<input>`, `<select>` | Form |

## CSS selectors

| Selector | What it selects |
|---|---|
| `p` | Tag |
| `.name` | Class |
| `#name` | ID |
| `.name p` | Descendant |
| `h1, h2` | Group |
| `*` | All elements |

## CSS properties

| Property | What it does |
|---|---|
| `display` | `block`, `inline`, `flex`, `grid`, `none` |
| `position` | `static`, `relative`, `absolute`, `fixed`, `sticky` |
| `margin`, `padding`, `border` | Box model |
| `width`, `height` | Size |
| `color`, `background-color` | Colors |
| `font-family`, `font-size`, `text-align` | Text |
| `justify-content`, `align-items`, `gap` | Alignment in flex and grid |
