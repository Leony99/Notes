# HTML and CSS

HTML defines the structure and the content of a page. CSS defines how it looks.

<a href="https://developer.mozilla.org/en-US/docs/Web/HTML" target="_blank">HTML Documentation</a>

<a href="https://developer.mozilla.org/en-US/docs/Web/CSS" target="_blank">CSS Documentation</a>

## Core concepts

- **Element**: A piece of the page, made of tags, attributes and content.
- **Attribute**: Extra information of an element (`id`, `class`, `href`).
- **Semantic tag**: A tag that describes its content (`header`, `nav`, `main`).
- **Selector**: Chooses the elements a CSS rule applies to.
- **Box model**: Every element is a box with content, padding, border and margin.
- **Specificity**: Decides which rule wins: inline > id > class > tag.
- **Cascade**: With the same specificity, the last rule wins.

## Connect CSS to HTML

*Example:*

```html
<link rel="stylesheet" href="style.css">
```

## Basic flow

```
index.html ──loads──▶ style.css + script.js ──▶ Browser renders the page
```
