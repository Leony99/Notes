# Document structure

Every HTML page has the same base.

- `<!DOCTYPE html>`: Describes the document type (only 'html' in HTML5) to browsers.
- `<html>`: The root element of the document, within it sit all other tags.
- `<head>`: Metadata, file links, images, CSS, JavaScript and links to third party data.
- `<body>`: The main body of content, the part displayed in the main browser window.

*Example:*

```html
<!DOCTYPE html>
<html>
    <head>
    </head>
    <body>
    </body>
</html>
```
