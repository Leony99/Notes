# Properties

## Positions

- static = positioned according to the normal flow of the page
- relative = positioned relative to its normal position in the flow
- absolute = position linked to the closest positioned parent element
- fixed = position linked to viewport
- sticky = behaves as relative until a scroll offset, then as fixed

```css
div {
    position: static;
    position: relative;
    position: absolute;
    position: fixed;
    position: sticky;
}
```

## Section formatting

- `width`, `height`: Size of the section.
- `margin`: Spacing outside the section.
- `border`: Section border.
- `padding`: Spacing inside the section.
- `box-sizing`: Defines if the padding and border will count in the width and height.

```css
div {
    width: auto;
    height: fit-content;
    margin: 10px;
    border: 3px solid green;
    padding: 15px;
    box-sizing: content-box;
    box-sizing: border-box;
}
```

## Colors

```css
div {
    color: red;
    color: #ff0000;
    color: rgb(255, 0, 0);
    color: rgba(255, 0, 0, 1);
}
```

## Text formatting

```css
div {
    font-family: Arial, Helvetica, sans-serif;
    font-size: 18px;
    text-align: center;
}
```
