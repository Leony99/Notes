# Grid

Grid organizes items in two directions, rows and columns.

## Container

```css
.container {
    display: grid;

    /*Specifies the number(and the heights) of rows in a grid layout.*/
    grid-template-rows: 1fr 1fr 1fr;

    /*Specifies the number(and the widths) of columns in a grid layout.*/
    grid-template-columns: 1fr 1fr 1fr;

    /*Defines the size of the gap between the rows and columns in a grid layout*/
    gap: 10px;
    row-gap: 10px;
    column-gap: 10px;

    /*Sets a size for the rows and columns*/
    grid-auto-rows: minmax(100px, auto);
    grid-auto-columns: minmax(100px, auto);

    /*Align items horizontally*/
    justify-items: stretch;
    /*Align items vertically*/
    align-items: stretch;
}
```

## Items

```css
.container #item-1 {
    /*Specifies a grid item's size and location*/
    grid-row: 1/3;
    grid-column: auto;

    /*Aligns just this item horizontally*/
    justify-self: end;

    /*Aligns just this item vertically*/
    align-self: end;
}
```

OBS: `fr` is a fraction of the available space. `1fr 1fr 1fr` creates three equal columns.
