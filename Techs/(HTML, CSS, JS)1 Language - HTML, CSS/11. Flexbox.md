# Flexbox

Flexbox organizes items in one direction, row or column.

## Container

```css
.container {
    display: flex;

    /*Items in a row / main-axis = horizontal / cross-axis = vertical*/
    flex-direction: row;
    /*Items in a column / main-axis = vertical / cross-axis = horizontal*/
    flex-direction: column;

    /*Aligns the items when they do not use all available space on the main-axis.*/
    justify-content: flex-start;

    /*Aligns the items when they do not use all available space on the cross-axis.*/
    align-items: center;

    /*Aligns the lines of a multi-line container (needs wrap) on the cross-axis.*/
    align-content: flex-start;

    /*Does not allow line break*/
    flex-flow: nowrap;
    /*Allow line break as soon as one of the items does not fit on it*/
    flex-flow: wrap;
}
```

## Items

```css
.container #item-1 {
    /*Defines the order of the item*/
    order: 1;

    /*Sets how much the item grows in the main-axis*/
    flex: 1;

    /*Sets the initial size of the item in the main-axis*/
    flex-basis: 100px;

    /*Pushes just this item to the end of the main-axis (justify-self has no effect in flexbox)*/
    margin-left: auto;

    /*Aligns just this item based in the cross-axis*/
    align-self: flex-end;
}
```
