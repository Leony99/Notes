# Tables

- `<table>`: Present data in a table.
- `<thead>`: Table header section.
- `<tbody>`: Table body section.
- `<tr>`: Table row.
- `<th>`: Table heading cell.
- `<td>`: Table data cell.

*Example:*

```html
<table>
    <thead>
        <tr>
            <th>Name</th>
            <th>Age</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>L</td>
            <td>23</td>
        </tr>
        <tr>
            <td>T</td>
            <td>27</td>
        </tr>
    </tbody>
</table>
```
