# Texts

- `<strong>`: Make text stronger or more important.
- `<em>`: Add emphasis to text.
- `<small>`: Define a smaller text.
- `<abbr>`: Insert an abbreviation.
- `<a>`: Anchor a hyperlink.
- `<blockquote>`: A long block quotation.

*Example:*

```html
<p>Lorem <strong>ipsum</strong> dolor sit amet.</p>
<p>Lorem <em>ipsum</em> dolor sit amet.</p>
<p><small>Lorem ipsum dolor sit amet.</small></p>
<p>Lorem <abbr title="Ipsum abbreviation">ipsum</abbr> dolor sit amet.</p>
<p>Lorem <a href="https://www.google.com.br" target="_blank">ipsum</a> dolor sit amet.</p>
<blockquote>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</blockquote>
```

OBS: `target="_blank"` opens the link in a new tab.
