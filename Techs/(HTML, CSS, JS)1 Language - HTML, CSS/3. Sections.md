# Sections

## Semantics

Semantic tags can be used to define different parts of the page.

```html
<header></header>
<nav></nav>
<main></main>
<section></section>
<article></article>
<aside></aside>
<footer></footer>
```

## Headings

Six section headings.

```html
<h1></h1>
<h2></h2>
<h3></h3>
<h4></h4>
<h5></h5>
<h6></h6>
```

## Others

- `<p>`: A paragraph section.
- `<div>`: A division or section in a document (block).
- `<span>`: A section inside a line of text (inline).
- `<br/>`: Line break.
- `<hr/>`: Horizontal line.

*Example:*

```html
<div>
    <p>A <span>paragraph</span><br/>with two lines</p>
    <hr/>
</div>
```
