# Head

The head holds information about the page. Its content is not displayed in the page.

- `<title>`: Document title, shown in the browser tab.
- `<link>`: Reference to a CSS document.
- `<script>`: Reference to a JavaScript document.
- `<meta>`: Metadata, like the charset and the viewport.

*Example:*

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="style.css">
    <script defer src="script.js"></script>
</head>
```

OBS: `defer` runs the script after the HTML is loaded, so it can find the elements of the page.
