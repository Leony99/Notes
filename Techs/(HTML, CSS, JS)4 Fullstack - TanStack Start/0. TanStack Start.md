# TanStack Start

A full-stack React framework built on TanStack Router and Vite.

[TanStack Start Docs](https://tanstack.com/start/latest/docs/framework/react/overview)

## Installation

**Via CLI:**
```console
npx @tanstack/cli@latest create
```
You'll be prompted to pick a package manager and optional add-ons (Tailwind, ESLint).

**From an example:**
```console
npx gitpick TanStack/router/tree/main/examples/react/start-basic start-basic
cd start-basic
npm install
npm run dev
```

## Core features

- Full-document SSR and streaming
- Server Routes & API Routes for backend endpoints
- Server Functions — type-safe RPCs between client and server
- Middleware & Context for request/response handling
- End-to-end TypeScript type safety

OBS: if you know you won't need SSR/server features, TanStack Router alone (without Start) is still a full type-safe SPA router.
