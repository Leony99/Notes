# Server Functions

Server-only logic callable from anywhere in the app — loaders, components, hooks — that runs on the server but is invoked like a normal function on the client.

*Example:*
```tsx
import { createServerFn } from '@tanstack/react-start'

// GET by default
export const getData = createServerFn().handler(async () => {
  return { message: 'Hello from server!' }
})

// POST
export const saveData = createServerFn({ method: 'POST' }).handler(async () => {
  return { success: true }
})
```

Call it from a route loader, a component (via `useServerFn()`), or another server function.

OBS: server functions are same-origin RPCs protected by CSRF middleware automatically, but reachable directly by their generated endpoint — independent of which route calls them. Apply auth checks inside the handler itself, not just a route-level guard.

## Validating input

*Example:*
```tsx
import { z } from 'zod'

const UserSchema = z.object({ name: z.string().min(1), age: z.number().min(0) })

export const createUser = createServerFn({ method: 'POST' })
  .inputValidator(UserSchema)
  .handler(async ({ data }) => {
    return `Created user: ${data.name}, age ${data.age}`
  })
```

## Errors, redirects and not-found

*Example:*
```tsx
import { redirect, notFound } from '@tanstack/react-router'

export const requireAuth = createServerFn().handler(async () => {
  const user = await getCurrentUser()
  if (!user) throw redirect({ to: '/login' })
  return user
})

export const getPost = createServerFn()
  .inputValidator((data: { id: string }) => data)
  .handler(async ({ data }) => {
    const post = await db.findPost(data.id)
    if (!post) throw notFound()
    return post
  })
```
