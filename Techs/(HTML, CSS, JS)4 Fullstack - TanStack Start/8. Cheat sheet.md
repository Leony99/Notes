# Cheat sheet

Quick reference of the most used TanStack Start features.

## Commands

| Command | What it does |
|---|---|
| `npx @tanstack/cli@latest create` | Creates a project |
| `npm run dev` | Starts the dev server |
| `npm run build` | Generates the production build |

## Routes

| File | Path |
|---|---|
| `routes/index.tsx` | `/` |
| `routes/about.tsx` | `/about` |
| `routes/posts/$postId.tsx` | `/posts/:postId` |
| `routes/rest/$.tsx` | `/rest/*` |
| `routes/__root.tsx` | Root route, always rendered |

## Functions

| Function | What it does |
|---|---|
| `createFileRoute(path)` | Defines a route |
| `Route.useLoaderData()` | Reads the loader data |
| `Route.useSearch()` | Reads the search params |
| `Route.useParams()` | Reads the path params |
| `useNavigate()` | Navigates from the code |
| `createServerFn()` | Creates a server function |
| `.inputValidator()` | Validates the input of a server function |
| `createMiddleware()` | Creates a middleware |
| `redirect()`, `notFound()` | Stops and redirects, or shows not found |

## Route options

| Option | What it does |
|---|---|
| `component` | The route interface |
| `loader` | Fetches data before rendering |
| `loaderDeps` | Declares the search params used by the loader |
| `validateSearch` | Validates the search params |
| `staleTime` | Time the loader data stays fresh |
| `errorComponent` | Shown when the loader fails |
| `server` | Server handlers of the route |
