# Routing

TanStack Start is built on top of TanStack Router — file-based routing lives in `src/routes`. Each filename maps to a URL path, and the router auto-generates a fully typed route tree from it.

*Example:*
```
src/routes/
├── index.tsx           →  /
├── about.tsx            →  /about
├── posts/$postId.tsx    →  /posts/:postId
├── rest/$.tsx            →  /rest/*
```
```tsx
// src/routes/posts/$postId.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/posts/$postId')({
  component: PostComponent,
})
```

OBS: the path string in `createFileRoute` is auto-managed by the router's bundler plugin — you don't need to update it by hand when moving files.

## Router setup

`src/router.tsx` creates the router instance from the generated route tree.

*Example:*
```tsx
import { createRouter } from '@tanstack/react-router'
import { routeTree } from './routeTree.gen'

export function getRouter() {
  return createRouter({ routeTree, scrollRestoration: true })
}
```

## Root route

`src/routes/__root.tsx` is always matched and always rendered — it's where the document shell (`<html>`, `<body>`) lives.

*Example:*
```tsx
import { Outlet, createRootRoute, HeadContent, Scripts } from '@tanstack/react-router'

export const Route = createRootRoute({
  component: () => (
    <html>
      <head><HeadContent /></head>
      <body>
        <Outlet />
        <Scripts />
      </body>
    </html>
  ),
})
```

OBS: `<Scripts />` loads the client-side JS and must always be included.

## Route tree generation

`src/routeTree.gen.ts` is auto-generated on `npm run dev` / `npm run start` and powers the router's type inference — don't edit it by hand.
