# Commands

Quick reference of the most used commands.

## mongosh

The MongoDB shell.

| Command | What it does |
|---|---|
| `mongosh "connection string"` | Connect to a database |
| `show dbs` | List the databases |
| `use my-app` | Change the database |
| `show collections` | List the collections |
| `db.users.find()` | List the documents |
| `db.users.findOne({ name: "John" })` | Find one document |
| `db.users.insertOne({ name: "John" })` | Insert a document |
| `db.users.updateOne(filter, { $set: {...} })` | Update a document |
| `db.users.deleteOne(filter)` | Delete a document |
| `db.users.countDocuments()` | Count the documents |
| `db.users.createIndex({ email: 1 })` | Create an index |

## Mongoose

| Method | What it does |
|---|---|
| `mongoose.connect(uri)` | Connect to the database |
| `new Schema({...})` | Define a schema |
| `model("User", schema)` | Create a model |
| `Model.create(data)` | Create a document |
| `Model.find(filter)` | Find documents |
| `Model.findById(id)` | Find by id |
| `Model.findByIdAndUpdate(id, update, options)` | Update by id |
| `Model.findByIdAndDelete(id)` | Delete by id |
| `Model.updateMany(filter, update)` | Update several documents |
| `Model.deleteMany(filter)` | Delete several documents |
| `query.populate("field")` | Fill a reference |
