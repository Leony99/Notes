# Mongo DB

MongoDB is a NoSQL database, which means it does not store data in tables and columns like a relational database. Instead, it uses a flexible JSON (or BSON) document structure, allowing you to store and query data without a fixed schema.

<a href="https://www.mongodb.com/pt-br/docs/atlas/" target="_blank">MongoDB Atlas Documentation</a>

<a href="https://www.mongodb.com/pt-br/docs/manual/" target="_blank">MongoDB Documentation</a>

## Installation

**Install the MongoDB driver:**

```console
npm install mongodb
```

**Run MongoDB locally with Docker:**

```console
docker run -d --name mongo -p 27017:27017 -v mongo-data:/data/db mongo:7
```

**Cloud:** Create a free cluster in MongoDB Atlas.

## Core concepts

- **Database**: A group of collections.
- **Collection**: A group of documents, like a table.
- **Document**: A BSON record, like a row.
- **Field**: A key and value of a document, like a column.
- **_id**: The unique identifier of a document, created automatically.

| SQL | MongoDB |
|---|---|
| Table | Collection |
| Row | Document |
| Column | Field |
| JOIN | `$lookup` / embedded documents |

*Example:*

```json
{
  "_id": "665f1c2e8a1b2c3d4e5f6a7b",
  "name": "John",
  "age": 25,
  "address": { "city": "Rio de Janeiro" },
  "tags": ["admin", "dev"]
}
```

## Connection string

**mongodb://[user:password@]host:port/database**

*Example:*

```
mongodb://localhost:27017/my-app
mongodb+srv://user:password@cluster.mongodb.net/my-app
```

OBS: Keep the connection string in an environment variable, as it can contain the password.
