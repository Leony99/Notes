# jQuery

jQuery is a JavaScript library that simplifies DOM selection and manipulation, events, animations and AJAX. Today most of it can be done with plain JavaScript, but it is still present in many existing projects.

<a href="https://api.jquery.com/" target="_blank">jQuery Documentation</a>

## Installation

**CDN:**

```html
<script src="https://code.jquery.com/jquery-3.7.1.min.js"
    integrity="sha256-/JqT3SQfawRcv/BIHPThkBvs0OEvtFFmqPF/lYI/Cxo=" crossorigin="anonymous"></script>
```

**Package Manager:**

```console
npm install jquery
```

## Core concepts

- **$**: The main function of jQuery, an alias for `jQuery`.
- **Selector**: A string that finds elements, using the CSS syntax.
- **jQuery object**: A collection of elements with the jQuery methods.
- **Chaining**: Most methods return the same object, so calls can be chained.

*Example:*

```javascript
$('#title').text('Hello').addClass('active').fadeIn(500);
```

## Document ready

Runs the code after the DOM is loaded. Not needed if the script is at the end of the body or uses `defer`.

```javascript
$(function() {
    console.log('Ready');
});
```
