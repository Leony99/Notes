# Manipulation

Methods that change the HTML, the attributes and the CSS of the selected elements.

## HTML

**.append/.prepend** - Add html to selected element.

```javascript
$('#conteudo1').append('<p>1</p>');
$('#conteudo2').append([
    $('<li>arroz</li>'),
    $('<li>feijão</li>'),
    $('<li>carne</li>')
]);
$('#conteudo2').prepend('<li>soja</li>');

$('<p>2</p>').appendTo('#conteudo1');
$('<p>0</p>').prependTo('#conteudo1');
```

**.before/.after** - Add html before/after selected element.

```javascript
$('#conteudo2').before('<p>New element</p>');
$('#conteudo2').after('<p>New element</p>');

$('<p>New element</p>').insertBefore('#conteudo2');
$('<p>New element</p>').insertAfter('#conteudo2');
```

**.html/.text** - Replace the content of selected element, as HTML or as text.

```javascript
$('#conteudo3').html('<p>lorem ipsum</p>');
$('#conteudo3').text('<p>lorem ipsum</p>');
```

**.replaceWith/.replaceAll** - Replace the selected element / replace multiple elements.

```javascript
$('#conteudo3').replaceWith('<div id="replaced"></div>');
$('<div id="replacedAgain"></div>').replaceAll('#replaced');
```

**.wrap/.wrapAll** - Wrap an element / wrap multiple elements.

```javascript
$('#conteudo4').wrap('<div>');
$('#conteudo5, #conteudo6').wrapAll('<div>');
```

**.empty/.remove** - Remove the content of selected element / remove an element.

```javascript
$('#conteudo4, #conteudo5, #conteudo6').empty();
$('#conteudo2').prev().remove();
```

## Attributes

**.attr** - Attribute manipulation.

```javascript
//Add attribute if no exists
$('div').attr('attr1', 'attr');
$('div').attr({attr2: 'attr', attr3: 'attr'});
//Change attribute if exists
$('#div1').attr('attr1', 'changed');
//Remove attribute
$('#div1').removeAttr('attr2').removeAttr('attr3');
//Get attribute value
$('#div1').attr('attr1');
```

**Class attribute:**

```javascript
//Add class
$('#div2').addClass('class');
$('#div3').addClass(['class', 'class2']);
//Remove class
$('#div3').removeClass('class2');
//Add or remove class
$('#div3').toggleClass('class');
//Determine if element has class
$('#div2').hasClass('class');
```

## CSS

**.css** - CSS manipulation.

```javascript
//Add property if no exists
$('div').css('background-color', 'red');
$('div').css({'width': '32px', 'height': '32px'});
//Change property if exists
$('#div2').css('background-color', 'green');
$('#div2').css('font-size', function() {
    return '32px';
});
//Get property value
$('#div3').css('font-family');
```
