# Plugin

A plugin adds a new method to all jQuery objects, by adding a function to `$.fn`.

- Use an IIFE, so `$` is jQuery even if `$` points to another object outside it.
- Add the function to `$.fn`.
- `return this` makes the plugin chainable (you can chain another function after this one).

*Example:*

```html
<div id="interpretationDiv">
    {{ 1 + 2 }} / {{ 3 ** 3 }} / {{ (function() { return 'Cool!!!' })() }}
</div>
```

```javascript
(function($) {
    //Compute a string as a javascript expression
    $.fn.interpretationPlugin = function() {
        const content = $(this).html();
        const expressionsWithBrackets = content.match(/{{(.*?)}}/g);
        const expressions = expressionsWithBrackets.map(text => text.substring(2, text.length - 2));
        const results = expressions.map(e => eval(e));

        let finalContent = content;
        for (let i = 0; i < results.length; i++) {
            finalContent = finalContent.replace(expressionsWithBrackets[i], results[i]);
        }
        $(this).html(finalContent);

        return this;
    }
})(jQuery)

$('#interpretationDiv').interpretationPlugin();
```

OBS: `eval` runs any code it receives. Use it only in studies, never with user input.
