# Selectors

jQuery uses the CSS selector syntax, plus some selectors of its own.

The examples use this HTML:

```html
<div>
    <ul id="feira">
        <li>Arroz</li>
        <li wm-obrigatorio>Feijão</li>
        <li class="opcional">Carne</li>
        <li class="opcional">Ovo</li>
    </ul>
</div>
<div>
    <p>Parágrafo <span class="negrito">span</span></p>
</div>
<form>
    <input type="text" name="texto">
    <input type="password" name="senha">
    <input type="checkbox" name="check1">
    <input type="radio" name="radio1">
    <input type="file" name="arquivo">
</form>
```

## Basic selectors

```javascript
//Tag selector
$('li')
//Attribute selector
$('[wm-obrigatorio]')
$('li[wm-obrigatorio]')
$('li[class="opcional"]')
//Id selector
$('#feira')
//Class selector
$('.negrito')
//Combinator selector
$('div p span')
//All elements inside 'ul'
$('ul *')
```

## Filter selectors

```javascript
//First/last element inside 'li'
$('li:first')
$('li:last')
//Odd index elements inside 'li'
$('li:odd')
//Greater Than index 'x' elements inside 'li'
$('li:gt(1)')
//Elements that contains "r" in list items
$('li:contains("r")')
```

## Form selectors

```javascript
$('form :text')
$('form :password')
$('form :checkbox')
$('form :radio')
$('form :file')
```

## Function selectors

```javascript
//Previous/next element
$('form :password').prev()
$('form :password').next()
//Parent element
$('form :password').parent()
//All parents chain
$('form :password').parents()
//All parents chain until selected element
$('form :password').parentsUntil($('html'))
//All children
$('form').children()
//All elements inside
$('body').find($('.opcional'))
```
