# Cheat sheet

Quick reference of the most used jQuery methods.

## Traversing

| Method | What it does |
|---|---|
| `.prev()`, `.next()` | Previous/next element |
| `.parent()`, `.parents()` | Parent, all parents |
| `.children()` | Children |
| `.find('selector')` | Elements inside |

## Manipulation

| Method | What it does |
|---|---|
| `.append()`, `.prepend()` | Add inside the element |
| `.before()`, `.after()` | Add around the element |
| `.html()`, `.text()`, `.val()` | Get or set the content or value |
| `.replaceWith()` | Replace the element |
| `.wrap()` | Wrap the element |
| `.empty()`, `.remove()` | Clear, remove |
| `.attr()`, `.removeAttr()` | Attributes |
| `.addClass()`, `.removeClass()`, `.toggleClass()`, `.hasClass()` | Classes |
| `.css()` | Styles |

## Events and animations

| Method | What it does |
|---|---|
| `.on()`, `.off()`, `.one()` | Bind, unbind, bind once |
| `.animate()` | Custom animation |
| `.hide()`, `.show()`, `.toggle()` | Visibility |
| `.fadeOut()`, `.fadeIn()`, `.fadeToggle()` | Fade |
| `.slideUp()`, `.slideDown()`, `.slideToggle()` | Slide |
