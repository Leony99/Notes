# Docker

Docker is a platform that packages an application and all its dependencies into a portable container, which runs the same way on any machine.

<a href="https://docs.docker.com/" target="_blank">Docker Documentation</a>

<a href="https://hub.docker.com/" target="_blank">Docker Hub</a>

## Installation

**Windows/Mac:** Install <a href="https://docs.docker.com/desktop/" target="_blank">Docker Desktop</a>.

**Linux:** Install <a href="https://docs.docker.com/engine/install/" target="_blank">Docker Engine</a>.

Verify the installation:

```console
docker --version
docker run hello-world
```

## Core concepts

- **Image**: A read-only template with the application and everything it needs to run.
- **Container**: A running instance of an image.
- **Dockerfile**: The file with the instructions to build an image.
- **Registry**: A place to store and share images (Docker Hub is the default one).
- **Volume**: Persistent storage that lives outside the container.
- **Network**: Allows containers to communicate with each other.
- **Docker Compose**: A tool to define and run multi-container applications.

OBS: An image is like a class and a container is like an object. One image can create several containers.

## Container vs Virtual Machine

A virtual machine runs a complete operating system. A container shares the host kernel and isolates only the process, so it is much lighter and starts in seconds.

| | Container | Virtual Machine |
|---|---|---|
| **Isolation** | Process | Complete operating system |
| **Size** | MBs | GBs |
| **Startup** | Seconds | Minutes |
| **Kernel** | Shared with the host | Own kernel |
