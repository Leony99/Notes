# Commands

Quick reference of the most used Docker commands.

## Images

| Command | What it does |
|---|---|
| `docker build -t name:tag .` | Builds an image from the Dockerfile |
| `docker pull name:tag` | Downloads an image |
| `docker push name:tag` | Sends an image to the registry |
| `docker images` | Lists the images |
| `docker rmi name:tag` | Removes an image |

## Containers

| Command | What it does |
|---|---|
| `docker run -d -p 8080:80 --name x image` | Creates and starts a container |
| `docker ps` | Lists the running containers |
| `docker ps -a` | Lists all containers |
| `docker stop x` | Stops a container |
| `docker start x` | Starts a stopped container |
| `docker rm x` | Removes a stopped container |
| `docker logs -f x` | Follows the logs |
| `docker exec -it x sh` | Opens a terminal in the container |

## Volumes and networks

| Command | What it does |
|---|---|
| `docker volume ls` | Lists the volumes |
| `docker volume rm x` | Removes a volume |
| `docker network ls` | Lists the networks |
| `docker network create x` | Creates a network |

## Compose

| Command | What it does |
|---|---|
| `docker compose up -d --build` | Builds and starts the services |
| `docker compose down` | Stops and removes the containers and the network |
| `docker compose logs -f x` | Follows the logs of a service |
| `docker compose exec x sh` | Opens a terminal in a service |

## Cleaning

| Command | What it does |
|---|---|
| `docker container prune` | Removes the stopped containers |
| `docker image prune` | Removes the dangling images |
| `docker volume prune` | Removes the unused volumes |
| `docker system prune` | Removes stopped containers, unused networks and dangling images |
| `docker system df` | Shows the disk usage of Docker |

OBS: The `prune` commands delete data permanently and ask for confirmation. `docker volume prune` deletes data that is not in any running container.
