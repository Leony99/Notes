# Dockerfile

A Dockerfile is a text file with the instructions to build an image. The file has no extension and is usually placed at the root of the project.

<a href="https://docs.docker.com/reference/dockerfile/" target="_blank">Dockerfile Reference</a>

## Instructions

- `FROM`: The base image. Every Dockerfile starts with it.
- `WORKDIR`: Sets the working directory of the next instructions.
- `COPY`: Copies files from the project to the image.
- `RUN`: Runs a command during the build.
- `ENV`: Defines an environment variable.
- `ARG`: Defines a variable available only during the build.
- `EXPOSE`: Documents the port used by the application. It does not publish the port.
- `USER`: Sets the user that runs the next instructions and the container.
- `CMD`: The default command when the container starts. Can be replaced in `docker run`.
- `ENTRYPOINT`: The fixed command when the container starts. `CMD` becomes its arguments.

OBS: `RUN` runs when the image is built, `CMD` and `ENTRYPOINT` run when the container starts.

*Example (Node.js):*

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./
RUN npm ci --omit=dev

COPY . .

EXPOSE 3000
USER node
CMD ["node", "dist/server.js"]
```

OBS: `package.json` is copied before the rest of the code to use the layer cache. `npm ci` only runs again when the dependencies change.

## .dockerignore

Lists the files that should not be sent to the build, like `.gitignore`.

*Example:*

```
node_modules
dist
target
.git
.env
```

OBS: Without it, `COPY . .` also copies `node_modules` and secrets from `.env` to the image.

## Multi-stage build

Uses one stage to build and another to run. Only the last stage goes to the final image, so build tools are left out and the image is much smaller.

*Example (React with Nginx):*

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
```

*Example (Spring Boot with Maven):*

```dockerfile
FROM maven:3.9-eclipse-temurin-21 AS build
WORKDIR /app
COPY pom.xml .
RUN mvn dependency:go-offline
COPY src ./src
RUN mvn clean package -DskipTests

FROM eclipse-temurin:21-jre
WORKDIR /app
COPY --from=build /app/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```
