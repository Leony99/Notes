# Images

An image is a read-only template used to create containers. It is built in layers, each instruction of the Dockerfile creates one. Layers are cached and shared between images, so builds and downloads reuse what has not changed.

## Name and tag

**[registry/][user/]name[:tag]**

- registry: blank = Docker Hub
- tag: blank = latest

*Example:*

```console
node:20-alpine
postgres:16
myuser/my-app:1.0.0
ghcr.io/myuser/my-app:1.0.0
```

OBS: Prefer a fixed tag over `latest`. `latest` is only a name, it can point to a different version tomorrow.

OBS: `-alpine` and `-slim` tags are smaller variants of an image.

## Download

```console
docker pull node:20-alpine
```

## Build

Build an image from the Dockerfile of the current directory ('.').

```console
docker build -t my-app:1.0.0 .
```

Use another Dockerfile:

```console
docker build -t my-app:1.0.0 -f Dockerfile.dev .
```

## Publish

- Log in to the registry.
- Tag the image with your user.
- Send the image.

```console
docker login
docker tag my-app:1.0.0 myuser/my-app:1.0.0
docker push myuser/my-app:1.0.0
```

## Manage

```console
docker images
docker history my-app:1.0.0
docker rmi my-app:1.0.0
docker image prune
```
