# Gradle

Gradle is a more modern and flexible build automation tool than Maven. Instead of XML, it uses a Groovy or Kotlin based script language (called DSL - Domain-Specific Language), which makes it more expressive and powerful. The main file is `build.gradle`. Gradle adopts a "convention over configuration" approach, offering greater freedom to customize the build process.

### Quick reference

| Command | What it does |
|---|---|
| `.\gradlew.bat build` | Compiles, tests and generates the `.jar` |
| `.\gradlew.bat test` | Runs the tests |
| `.\gradlew.bat clean` | Cleans the `build/` folder |
| `.\gradlew.bat bootRun` | Runs a Spring Boot application |
| `.\gradlew.bat dependencies` | Lists all dependencies |
