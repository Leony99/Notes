# Performance hooks

A component re-renders when its state changes or its parent re-renders. These tools avoid unnecessary work.

OBS: Use them when you measure a real problem. React is fast by default.

## useMemo

Caches the result of a calculation between renders.

```jsx
const value = useMemo(() => calculation, dependencies);
```

*Example:*

```jsx
const visibleTodos = useMemo(() => filterTodos(todos, tab), [todos, tab]);
```

## useCallback

Caches a function between renders. Useful when the function is passed to a memoized child.

```jsx
const fn = useCallback(() => {}, dependencies);
```

*Example:*

```jsx
const handleSubmit = useCallback((data) => {
    post(`/product/${productId}`, data);
}, [productId]);
```

## memo

Skips the re-render of a component if its props did not change.

*Example:*

```jsx
import { memo } from 'react';

const Greeting = memo(function Greeting({ name }) {
    return <h1>Hello, {name}!</h1>;
});
```

## useReducer

Not a performance hook, but an alternative to useState for complex state: the logic of the updates stays in one function.

```jsx
const [state, dispatch] = useReducer(reducer, initialState);
```

*Example:*

```jsx
function reducer(state, action) {
    switch (action.type) {
        case 'increment':
            return { count: state.count + 1 };
        case 'reset':
            return { count: 0 };
        default:
            return state;
    }
}

function Counter() {
    const [state, dispatch] = useReducer(reducer, { count: 0 });

    return <button onClick={() => dispatch({ type: 'increment' })}>{state.count}</button>;
}
```
