# Custom hooks

A custom hook is a function that starts with `use` and calls other hooks. It reuses logic between components, not the state itself: each call has its own state.

*Example:*

```jsx
import { useState, useEffect } from 'react';

export function useFetch(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);

    useEffect(() => {
        let ignore = false;

        setLoading(true);
        fetch(url)
            .then((res) => res.json())
            .then((json) => {
                if (!ignore) {
                    setData(json);
                    setLoading(false);
                }
            });

        return () => {
            ignore = true;
        };
    }, [url]);

    return { data, loading };
}
```

```jsx
function UserProfile({ id }) {
    const { data: user, loading } = useFetch(`/api/users/${id}`);

    if (loading) return <p>Loading...</p>;

    return <h1>{user.name}</h1>;
}
```

## Rules of hooks

- Call hooks only at the top level of a component or custom hook.
- Don't call hooks inside conditions or loops.
- Call hooks only from React functions.
