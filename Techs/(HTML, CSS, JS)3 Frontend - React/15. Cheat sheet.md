# Cheat sheet

Quick reference of the most used React features.

## Hooks

| Hook | What it does |
|---|---|
| `useState(initial)` | Remembers a value and re-renders when it changes |
| `useRef(initial)` | Remembers a value without re-rendering, or a DOM node |
| `useEffect(fn, deps)` | Synchronizes with an external system |
| `useContext(Context)` | Reads a context |
| `useReducer(reducer, initial)` | State with the update logic in a function |
| `useMemo(fn, deps)` | Caches a calculated value |
| `useCallback(fn, deps)` | Caches a function |

## useEffect dependencies

| Dependencies | When it runs |
|---|---|
| None | After every render |
| `[]` | After the initial render |
| `[a, b]` | After the initial render and when `a` or `b` change |

## JSX

| Syntax | What it does |
|---|---|
| `{value}` | Shows a JavaScript value |
| `className="box"` | CSS class |
| `style={{ color: 'red' }}` | Inline style |
| `onClick={fn}` | Event |
| `{a ? <X /> : <Y />}` | Conditional |
| `{a && <X />}` | Render only if true |
| `{list.map((i) => <X key={i.id} />)}` | List |
| `<>...</>` | Fragment |
| `{children}` | Content between the tags |

## Commands

| Command | What it does |
|---|---|
| `npm create vite@latest` | Creates a project |
| `npm run dev` | Starts the dev server |
| `npm run build` | Generates the production build |
| `npm run preview` | Serves the production build locally |
