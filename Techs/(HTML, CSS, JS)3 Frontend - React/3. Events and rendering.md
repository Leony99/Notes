# Events and rendering

## Events

Events are passed as camelCase props, and receive a function.

- onClick
- onChange
- onSubmit
- onKeyDown
- onMouseEnter

*Example:*

```jsx
function Form() {
    function handleSubmit(e) {
        e.preventDefault();
        console.log('Sent');
    }

    return (
        <form onSubmit={handleSubmit}>
            <button type="submit">Send</button>
        </form>
    );
}
```

OBS: Pass the function, don't call it. `onClick={handleClick}` is right, `onClick={handleClick()}` runs during the render. To pass an argument, use `onClick={() => handleClick(id)}`.

## Controlled inputs

The value of the input is stored in the state.

*Example:*

```jsx
function SearchBox() {
    const [text, setText] = useState('');

    return <input value={text} onChange={(e) => setText(e.target.value)} />;
}
```

## Conditional rendering

*Example:*

```jsx
function Status({ isLogged, name }) {
    if (!name) return null;

    return (
        <div>
            {isLogged ? <Dashboard /> : <Login />}
            {isLogged && <p>Welcome, {name}</p>}
        </div>
    );
}
```

OBS: `{count && <p>...</p>}` renders `0` when count is 0. Use `{count > 0 && <p>...</p>}`.

## Rendering lists

Use `map` to turn an array into elements. Each element needs a unique `key`.

*Example:*

```jsx
function TodoList({ todos }) {
    return (
        <ul>
            {todos.map((todo) => (
                <li key={todo.id}>{todo.title}</li>
            ))}
        </ul>
    );
}
```

OBS: The key identifies the item between renders. Avoid the array index when the list can change order.

## Styling

*Example:*

```jsx
<div className="box" style={{ color: 'red', fontSize: 16 }}>Text</div>
```

OBS: In JSX, `class` is `className` and `style` receives an object.
