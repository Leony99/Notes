# React Hook Form

React Hook Form is a library to manage forms in React with less code and fewer re-renders. It uses uncontrolled inputs, so the component does not re-render on every keystroke.

<a href="https://react-hook-form.com/docs" target="_blank">React Hook Form Documentation</a>

## Installation

**npm:**

```console
npm install react-hook-form
```

## Use

- Call the useForm hook.
- Connect the inputs with the register function.
- Wrap the submit function with handleSubmit.

*Example:*

```jsx
import { useForm } from 'react-hook-form';

export default function LoginForm() {
  const { register, handleSubmit } = useForm();

  function onSubmit(data) {
    console.log(data); // { email: '...', password: '...' }
  }

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('email')} />
      <input type="password" {...register('password')} />
      <button type="submit">Login</button>
    </form>
  );
}
```

## Validation

Pass the validation rules as the second argument of register. The errors are available in `formState`.

- required
- minLength/maxLength
- min/max
- pattern
- validate

*Example:*

```jsx
const { register, handleSubmit, formState: { errors } } = useForm();

<form onSubmit={handleSubmit(onSubmit)}>
  <input
    {...register('email', {
      required: 'Email is required',
      pattern: { value: /^\S+@\S+$/, message: 'Invalid email' },
    })}
  />
  {errors.email && <p>{errors.email.message}</p>}

  <input
    type="password"
    {...register('password', {
      required: 'Password is required',
      minLength: { value: 8, message: 'Minimum of 8 characters' },
    })}
  />
  {errors.password && <p>{errors.password.message}</p>}

  <button type="submit">Login</button>
</form>
```

## Default values

*Example:*

```jsx
const { register } = useForm({
  defaultValues: {
    email: 'john@example.com',
    password: '',
  },
});
```

## Other functions

- `reset()`: Resets the form values.
- `setValue(name, value)`: Changes the value of a field.
- `watch(name)`: Observes the value of a field (re-renders when it changes).
- `formState.isSubmitting`: Indicates that the form is being submitted.

*Example:*

```jsx
const { register, handleSubmit, reset, formState: { isSubmitting } } = useForm();

async function onSubmit(data) {
  await saveUser(data);
  reset();
}

<button type="submit" disabled={isSubmitting}>Save</button>
```

## Schema validation

You can validate the whole form with a schema library like Zod, using the `@hookform/resolvers` package.

```console
npm install @hookform/resolvers zod
```

*Example:*

```jsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const schema = z.object({
  email: z.string().email('Invalid email'),
  password: z.string().min(8, 'Minimum of 8 characters'),
});

const { register, handleSubmit, formState: { errors } } = useForm({
  resolver: zodResolver(schema),
});
```
