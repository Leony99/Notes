# Components

Bootstrap provides ready-made components. Some need the JavaScript bundle, and are configured by `data-bs-*` attributes.

<a href="https://getbootstrap.com/docs/5.3/components/" target="_blank">Bootstrap Components Documentation</a>

## Buttons

**btn btn-{color}** or **btn btn-outline-{color}**

*Example:*

```html
<button class="btn btn-primary">Primary</button>
<button class="btn btn-outline-danger">Danger</button>
<button class="btn btn-success btn-lg">Large</button>
```

## Cards

*Example:*

```html
<div class="card" style="width: 18rem;">
  <img src="path/to/image.jpg" class="card-img-top" alt="...">
  <div class="card-body">
    <h5 class="card-title">Title</h5>
    <p class="card-text">Text</p>
    <a href="#" class="btn btn-primary">Go</a>
  </div>
</div>
```

## Forms

*Example:*

```html
<form>
  <div class="mb-3">
    <label for="email" class="form-label">Email</label>
    <input type="email" class="form-control" id="email">
  </div>
  <div class="mb-3">
    <select class="form-select">
      <option value="1">One</option>
    </select>
  </div>
  <button type="submit" class="btn btn-primary">Send</button>
</form>
```

## Navbar

*Example:*

```html
<nav class="navbar navbar-expand-lg bg-body-tertiary">
  <div class="container">
    <a class="navbar-brand" href="#">Brand</a>
    <button class="navbar-toggler" data-bs-toggle="collapse" data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav">
        <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
      </ul>
    </div>
  </div>
</nav>
```

## Modal

*Example:*

```html
<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">Open</button>

<div class="modal fade" id="myModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Title</h5>
        <button class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">Content</div>
    </div>
  </div>
</div>
```

## Alerts

**alert alert-{color}**

*Example:*

```html
<div class="alert alert-warning" role="alert">Warning!</div>
```
