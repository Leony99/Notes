# Classes

Quick reference of the most used Bootstrap classes.

## Layout

| Class | What it does |
|---|---|
| `container` | Fixed-width container |
| `container-fluid` | 100% wide container |
| `row` | Grid row |
| `col`, `col-6`, `col-md-4` | Grid column |
| `offset-2` | Moves a column to the right |
| `order-1` | Changes the visual order |
| `w-100` | Line break between columns |

## Spacing

| Class | What it does |
|---|---|
| `m-3`, `mt-2`, `mx-auto` | Margin |
| `p-3`, `pb-2`, `px-4` | Padding |
| `gap-2` | Gap in grid and flex containers |

## Flex and display

| Class | What it does |
|---|---|
| `d-flex`, `d-inline-flex`, `d-grid` | Display |
| `d-none`, `d-md-block` | Hide and show by breakpoint |
| `flex-row`, `flex-column` | Direction |
| `justify-content-between` | Main-axis alignment |
| `align-items-center` | Cross-axis alignment |

## Text and colors

| Class | What it does |
|---|---|
| `text-center`, `text-end` | Text alignment |
| `fw-bold`, `fst-italic` | Font weight and style |
| `fs-1` to `fs-6` | Font size |
| `text-primary`, `bg-primary` | Text and background color |

## Others

| Class | What it does |
|---|---|
| `border`, `border-top`, `border-0` | Borders |
| `rounded`, `rounded-circle` | Rounded borders |
| `shadow`, `shadow-lg` | Shadows |
| `img-fluid`, `img-thumbnail` | Images |
| `btn btn-primary` | Button |
